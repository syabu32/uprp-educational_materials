# 音を鳴らす

配線とmicroSDカードの準備ができたので、実際に音を鳴らしてみましょう。

DFPlayerへの命令は決まった形のデータをUARTで送る必要があり、自分で作ると大変です。そこで、命令を代わりに作ってくれる **ライブラリ** を使います。

## ライブラリのインストール

[セットアップ](../セットアップ.md)の章で、左の本棚のマーク(ライブラリマネージャー)から **DFRobotDFPlayerMini** をインストールしました。まだの人はインストールしておきましょう。

## 1番と2番の音を交互に鳴らす

microSDカードの`mp3`フォルダに`0001.mp3`と`0002.mp3`を入れておきます。

```cpp
#include <DFRobotDFPlayerMini.h>

DFRobotDFPlayerMini dfPlayer;

void setup() {
    Serial.begin(9600);    //シリアルモニタ用
    Serial1.begin(9600);   //DFPlayer用(18番・19番)

    if (!dfPlayer.begin(Serial1)) {
        Serial.println("DFPlayerが見つかりません");
        while (true) {
        }
    }
    Serial.println("DFPlayerの準備ができました");

    dfPlayer.volume(20);   //音量(0〜30)
}

void loop() {
    dfPlayer.playMp3Folder(1);
    Serial.println("0001.mp3を再生");
    delay(3000);

    dfPlayer.playMp3Folder(2);
    Serial.println("0002.mp3を再生");
    delay(3000);
}
```

このコードは次のように出力されます。

```
DFPlayerの準備ができました
0001.mp3を再生
0002.mp3を再生
0001.mp3を再生
0002.mp3を再生
.
.
.
```

## 1行ずつ見ていく

**`#include <DFRobotDFPlayerMini.h>`**

インストールしたライブラリを使えるようにします。ライブラリを使うときは、プログラムの一番上に必ず書きます。

**`DFRobotDFPlayerMini dfPlayer;`**

ライブラリが用意した`DFRobotDFPlayerMini`という設計図から、`dfPlayer`という **実物** を作ります。構造体の章の`Motor leftMotor = {5, 22, 23};`と同じ考え方で、このあとは`dfPlayer.命令()`の形でDFPlayerに命令を出します。

**`Serial1.begin(9600);`**

DFPlayerを繋いだSerial1(18番・19番)を9600で使い始めます。シリアルモニタ用の`Serial`とは別のUARTなので、両方`begin()`します。

**`dfPlayer.begin(Serial1)`**

「DFPlayerはSerial1に繋がっている」と教えて、DFPlayerと通信を始めます。DFPlayerから返事があれば`true`、なければ`false`になります。配線が間違っているときやmicroSDカードが入っていないときは`false`になり、`if`の中で「見つかりません」と表示したあと`while (true)`で止まります。

**`dfPlayer.volume(20);`**

音量を **0〜30** で決めます。0で無音、30が最大です。

**`dfPlayer.playMp3Folder(1);`**

`mp3`フォルダの`0001.mp3`を再生します。`()`の中の数字がファイル名の番号です。

## ライブラリが送っている通信

`dfPlayer.playMp3Folder(1)`と書いたとき、ライブラリはSerial1のTX1(18番)から、DFPlayerのRXへ **10バイト** のデータを送っています。1バイトは0〜255の数で、ここでは`7E`のように **16進数** (0〜9とA〜Fの2けた)で書きます。

| 順番 | 送る値 | 意味 |
| --- | --- | --- |
| 1 | `7E` | 始まりの印(いつも同じ) |
| 2 | `FF` | バージョン(いつも同じ) |
| 3 | `06` | 長さ(いつも同じ) |
| 4 | `12` | **命令の種類** (`12`は「mp3フォルダの番号のファイルを再生」) |
| 5 | `01` | 返事がほしいか(`01`は「ほしい」) |
| 6 | `00` | **命令の値** の上の桁 |
| 7 | `01` | **命令の値** の下の桁(`00 01`で1番) |
| 8 | `FE` | チェックサムの上の桁 |
| 9 | `E7` | チェックサムの下の桁 |
| 10 | `EF` | 終わりの印(いつも同じ) |

- **命令の種類と値**: 4番目と6・7番目だけが命令ごとに変わります。たとえば`dfPlayer.volume(20)`なら、命令の種類が`06`(音量)、値が`00 14`(16進数の`14`は20)になり、`7E FF 06 06 01 00 14 FE E0 EF`を送ります
- **チェックサム**: 2〜7番目の値を足した合計から作る確認用の数です。途中でデータが化けると合計が合わなくなるので、DFPlayerは届いたデータが正しいか確かめられます

DFPlayerは命令を受け取ると、同じ10バイトの形で **返事** をTXからマイコンのRX1(19番)へ送り返します。`dfPlayer.begin(Serial1)`が`true`か`false`かわかるのは、この返事が届いたかどうかを見ているからです。RX1の線が抜けていると、命令は届いて音が鳴っても、`begin()`は`false`になります。

この10バイトとチェックサムを毎回自分で計算するのは大変でまちがえやすいので、ライブラリに任せます。私たちは「何番を鳴らすか」だけを書けばよくなります。

## 再生は待ってくれない

`playMp3Folder()`は **命令を送ったらすぐ次の行に進みます**。音が鳴り終わるのを待ちません。上のコードで`delay(3000)`を書いているのは、音を聞く時間を作るためです。

鳴っている途中で次の`playMp3Folder()`を送ると、前の音は途中で止まって新しい音に切り替わります。

!!! warning "`play()`ではなく`playMp3Folder()`を使いましょう"

    ライブラリには`play(1)`という命令もありますが、これはファイル名ではなく **microSDカードにファイルをコピーした順番** で再生します。ファイル名の番号の通りに鳴らしたいときは`playMp3Folder()`を使います。

## 演習

`0001.mp3`を、音量10 → 20 → 30の順に大きくしながら2秒ずつ鳴らすプログラムを書いてください。音量を変えるたびに、シリアルモニタに音量を表示しましょう。`setup()`は上のコードと同じで、`volume(20)`の行はなくしてかまいません。

??? tip "ヒントを見る"

    音量は10ずつ増えるので、繰り返しの章の`for`が使えます。

    | やること | 書き方 |
    | --- | --- |
    | 1. 10から30まで10ずつ増やす | `for (int vol = 10; vol <= 30; vol += 10)` |
    | 2. 音量を変える | `dfPlayer.volume(vol);` |
    | 3. 音量を表示する | `Serial.print("音量: ");` と `Serial.println(vol);` |
    | 4. 再生する | `dfPlayer.playMp3Folder(1);` |
    | 5. 2秒待つ | `delay(2000);` |

    2〜5を`for`の`{ }`の中に書きます。

??? success "答えを見る"

    ```cpp
    #include <DFRobotDFPlayerMini.h>

    DFRobotDFPlayerMini dfPlayer;

    void setup() {
        Serial.begin(9600);    //シリアルモニタ用
        Serial1.begin(9600);   //DFPlayer用(18番・19番)

        if (!dfPlayer.begin(Serial1)) {
            Serial.println("DFPlayerが見つかりません");
            while (true) {
            }
        }
        Serial.println("DFPlayerの準備ができました");
    }

    void loop() {
        for (int vol = 10; vol <= 30; vol += 10) {
            dfPlayer.volume(vol);
            Serial.print("音量: ");
            Serial.println(vol);

            dfPlayer.playMp3Folder(1);
            delay(2000);
        }
    }
    ```

    出力は次のようになります。

    ```
    DFPlayerの準備ができました
    音量: 10
    音量: 20
    音量: 30
    音量: 10
    .
    .
    .
    ```

    30のあとは`loop()`の最初に戻るので、また10から始まります。

## 脳内実行してみよう

上の`setup()`のあと、`loop()`を次のように書き換えました。スピーカーからはどの音が、どんな順番で聞こえるでしょうか。どの音も長さは3秒あるものとします。

```cpp
void loop() {
    dfPlayer.playMp3Folder(1);
    dfPlayer.playMp3Folder(2);
    delay(5000);

    dfPlayer.playMp3Folder(3);
    delay(1000);
    dfPlayer.playMp3Folder(1);
    delay(5000);
}
```

??? success "答えを見る"

    **2番(3秒)→ 少し静か → 3番(最初の1秒だけ)→ 1番(3秒)→ 少し静か** の順に聞こえ、これを繰り返します。最初の`playMp3Folder(1)`の音はほとんど聞こえません。

    | 実行する行 | 聞こえる音 |
    | --- | --- |
    | `playMp3Folder(1);` | 1番が鳴り始める |
    | `playMp3Folder(2);` | すぐに2番に切り替わる(1番はほぼ聞こえない) |
    | `delay(5000);` | 2番が3秒鳴って終わり、残り2秒は静か |
    | `playMp3Folder(3);` | 3番が鳴り始める |
    | `delay(1000);` | 3番が1秒鳴る |
    | `playMp3Folder(1);` | 3番が途中で止まり、1番に切り替わる |
    | `delay(5000);` | 1番が3秒鳴って終わり、残り2秒は静か |

    `playMp3Folder()`は音が終わるのを待たないので、`delay()`を挟まずに続けて書くと、**最後に送った命令の音だけ** が聞こえます。
