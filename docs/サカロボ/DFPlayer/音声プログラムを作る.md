# 音声プログラムを作る

最終的なロボットのプログラムで使う「音声を流すプログラム」を作ります。前の章のコードをそのままロボットに入れると、困ることが2つあります。

- `playMp3Folder(2)`と書いても、**2番が何の音か** コードを読んだだけではわからない
- DFPlayerが見つからないと`while (true)`で止まるので、**音が鳴らないだけでロボットが動かなくなる**

この2つを直して、モータードライバの章で作った`Motor`と一緒に使ってみます。

```cpp
#include <DFRobotDFPlayerMini.h>

#define SOUND_START 1   //mp3/0001.mp3 起動したときの音声
#define SOUND_GO 2      //mp3/0002.mp3 走り出すときの音声
#define SOUND_STOP 3    //mp3/0003.mp3 止まるときの音声

DFRobotDFPlayerMini dfPlayer;
bool soundReady = false;   //DFPlayerが使えるならtrue

//DFPlayerを準備する(setupで1回呼ぶ)
void beginSound(int volume) {
    if (volume > 30) {
        volume = 30;
    } else if (volume < 0) {
        volume = 0;
    }

    Serial1.begin(9600);
    soundReady = dfPlayer.begin(Serial1);

    if (soundReady) {
        dfPlayer.volume(volume);
        Serial.println("DFPlayerの準備ができました");
    } else {
        Serial.println("DFPlayerが見つかりません(音なしで動きます)");
    }
}

//音声を流す
void playSound(int number) {
    if (soundReady) {
        dfPlayer.playMp3Folder(number);
    }
}

struct Motor {
    int en;    //ENAを繋いだピン(PWM)
    int in1;   //IN1を繋いだピン
    int in2;   //IN2を繋いだピン

    //ブレーキで止める
    void stop() {
        digitalWrite(in1, LOW);
        digitalWrite(in2, LOW);
        analogWrite(en, 255);
    }

    //ピンを出力モードにして、止まった状態から始める(setupで1回呼ぶ)
    void begin() {
        pinMode(en, OUTPUT);
        pinMode(in1, OUTPUT);
        pinMode(in2, OUTPUT);
        stop();
    }

    //speedが+なら正転、-なら逆転、0なら停止(-255〜255)
    void run(int speed) {
        if (speed > 255) {
            speed = 255;
        } else if (speed < -255) {
            speed = -255;
        }

        if (speed > 0) {
            digitalWrite(in1, HIGH);
            digitalWrite(in2, LOW);
            analogWrite(en, speed);
        } else if (speed < 0) {
            digitalWrite(in1, LOW);
            digitalWrite(in2, HIGH);
            analogWrite(en, -speed);   //analogWriteには+の値を渡す
        } else {
            stop();
        }
    }
};

Motor leftMotor = {5, 22, 23};

void setup() {
    Serial.begin(9600);
    leftMotor.begin();
    beginSound(20);

    playSound(SOUND_START);
    Serial.println("起動");
    delay(2000);
}

void loop() {
    playSound(SOUND_GO);
    leftMotor.run(200);
    Serial.println("走る");
    delay(3000);

    playSound(SOUND_STOP);
    leftMotor.run(0);
    Serial.println("止まる");
    delay(2000);
}
```

DFPlayerが繋がっているときは、次のように出力されます。

```
DFPlayerの準備ができました
起動
走る
止まる
走る
止まる
.
.
.
```

## 音の番号に名前を付ける

`#define SOUND_GO 2`のように、音の番号に名前を付けています。`playSound(SOUND_GO)`と書けば、コードを読むだけで「走り出すときの音声」だとわかります。

microSDカードのファイルとの対応は、`#define`の行のコメントにまとめて書いておきます。音を入れ替えたときも、ここを見れば何番が何の音かすぐにわかります。

## 見つからなくても止まらない

`dfPlayer.begin(Serial1)`の結果(`true`か`false`)を、`bool`型の変数`soundReady`に入れて覚えておきます。

- `beginSound()`: 見つからなかったら「音なしで動きます」と表示するだけで、`while (true)`では止めない
- `playSound()`: `soundReady`が`true`のときだけ`playMp3Folder()`を送る

こうしておくと、DFPlayerの配線が抜けていても、**音が鳴らないだけでモーターは動きます**。試合中に一番困るのはロボットが動かなくなることなので、音のような「なくても動ける部品」は、失敗しても先に進めるように作ります。

`beginSound()`の最初で音量を0〜30に直しているのは、`Motor`の`run()`で速さを-255〜255に直したのと同じ安全装置です。

## 音とモーターは同時に動く

前の章で説明したように、`playSound()`は音が鳴り終わるのを待たずに次の行に進みます。そのため`playSound(SOUND_GO)`のすぐあとの`leftMotor.run(200)`で、**音が鳴り始めるのとほぼ同時にモーターが回り出します**。

もし音が鳴り終わるまで待つ仕組みだったら、音声が2秒あるとその間ロボットが動けなくなってしまいます。

## 使い方

| 書き方 | 意味 |
| --- | --- |
| `#define SOUND_名前 番号` | 音の番号に名前を付ける |
| `beginSound(20);` | 音量20でDFPlayerを準備する(`setup()`で1回) |
| `playSound(SOUND_GO);` | 走り出すときの音声を流す |

音声を増やすときは、microSDカードの`mp3`フォルダに`0004.mp3`を入れて、`#define`を1行足すだけです。`beginSound()`と`playSound()`の中身は書き換えません。

## 演習

`mp3`フォルダに逆転するときの音声`0004.mp3`を入れました。上のプログラムの`loop()`に「逆転するときの音声を流して、速さ150で逆転を3秒 → 止まるときの音声を流して停止を2秒」を **止まったあとに** 追加してください。

??? tip "ヒントを見る"

    変えるのは3か所だけです。`beginSound()`・`playSound()`・`Motor`の中は触りません。

    | やること | 書き方 |
    | --- | --- |
    | 1. 逆転するときの音声に名前を付ける | `#define SOUND_BACK 4` |
    | 2. 逆転するときの音声を流して逆転する | `playSound(SOUND_BACK);` と `leftMotor.run(-150);` |
    | 3. 止まるときの音声を流して止まる | `playSound(SOUND_STOP);` と `leftMotor.run(0);` |

    それぞれのあとに`delay()`を書くのを忘れないようにしましょう。

??? success "答えを見る"

    変わるのは`#define`と`loop()`だけなので、そこだけ示します。`beginSound()`・`playSound()`・`Motor`・`setup()`は上のコードと同じです。

    ```cpp
    #define SOUND_START 1   //mp3/0001.mp3 起動したときの音声
    #define SOUND_GO 2      //mp3/0002.mp3 走り出すときの音声
    #define SOUND_STOP 3    //mp3/0003.mp3 止まるときの音声
    #define SOUND_BACK 4    //mp3/0004.mp3 逆転するときの音声

    void loop() {
        playSound(SOUND_GO);
        leftMotor.run(200);
        Serial.println("走る");
        delay(3000);

        playSound(SOUND_STOP);
        leftMotor.run(0);
        Serial.println("止まる");
        delay(2000);

        playSound(SOUND_BACK);
        leftMotor.run(-150);
        Serial.println("逆転");
        delay(3000);

        playSound(SOUND_STOP);
        leftMotor.run(0);
        Serial.println("止まる");
        delay(2000);
    }
    ```

    出力は次のようになります。

    ```
    DFPlayerの準備ができました
    起動
    走る
    止まる
    逆転
    止まる
    走る
    .
    .
    .
    ```

## 脳内実行してみよう

上のプログラムを、**DFPlayerのRXの線が抜けた状態** で動かしました。`setup()`が終わって`loop()`を1回実行し終わるまでに、シリアルモニタには何が表示されるでしょうか。また、スピーカーとモーターはどうなるでしょうか。

??? success "答えを見る"

    ```
    DFPlayerが見つかりません(音なしで動きます)
    起動
    走る
    止まる
    ```

    スピーカーからは **何も鳴りません** が、モーターは **いつも通り「走る→止まる」と動きます**。

    | 実行する行 | `soundReady` | 何が起きるか |
    | --- | --- | --- |
    | `soundReady = dfPlayer.begin(Serial1);` | false | 返事がないので`false`が入る |
    | `if (soundReady)` | false | 違うので`else`へ。「見つかりません」と表示 |
    | `playSound(SOUND_START);` | false | `if (soundReady)`が違うので何もしない |
    | `Serial.println("起動");` | false | 「起動」と表示 |
    | `playSound(SOUND_GO);` | false | 何もしない |
    | `leftMotor.run(200);` | false | モーターが正転する |
    | `Serial.println("走る");` | false | 「走る」と表示 |
    | `playSound(SOUND_STOP);` | false | 何もしない |
    | `leftMotor.run(0);` | false | モーターが止まる |
    | `Serial.println("止まる");` | false | 「止まる」と表示 |

    `soundReady`は`beginSound()`の中で一度`false`になったら、そのあとずっと`false`のままです。なので`playSound()`は毎回何もせずに戻りますが、`Motor`は`soundReady`と関係なく動きます。前の章のように`while (true)`で止めていたら、「起動」から先は何も表示されず、モーターも動きませんでした。
