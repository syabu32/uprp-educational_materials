# DFPlayerを知る

ここからはロボットから音を鳴らすプログラムを作っていきます。まずは[全体像を知る](../全体像を知る.md)で選んだDFPlayer Mini(DFPlayer)の使い方を調べていきましょう。

DFPlayerは、microSDカードに入れた音声ファイルを自分で読み込んで、スピーカーを鳴らすところまでやってくれます。マイコンは「◯番のファイルを再生して」という **命令だけ** をUARTで送ります。音のデータを処理するのはDFPlayerなので、マイコンの負担はほとんどありません。

## 端子の説明

DFPlayerには左右に8本ずつ、合わせて16本の端子があります。サカロボで使うのは次の6本です。

| 端子 | 役割 | 繋ぐ先 |
| --- | --- | --- |
| VCC | 電源の+(3.2〜5V) | マイコンの5V |
| GND | 電源の- | マイコンのGND |
| RX | 命令を **受信** する | マイコンの **TX1(18番)** |
| TX | 返事を **送信** する | マイコンの **RX1(19番)** |
| SPK_1・SPK_2 | スピーカーへの出力(アンプ出力) | スピーカー |

残りの端子(DAC_R・DAC_L・BUSY・IO_1・IO_2・ADKEY_1・ADKEY_2・USB+・USB-)は今回は使いません。GNDは2本ありますが、どちらを使っても同じです。

[Arduino_Mega2560を知る](../Arduino_Mega2560を知る.md)のUARTで説明したように、**自分のTXを相手のRXに、自分のRXを相手のTXに** 繋ぎます。マイコンが送った命令(TX)をDFPlayerが受け取る(RX)ので、TXとRXが入れ替わるのが正しい配線です。

!!! warning "0番・1番ピン(Serial0)には繋がないでください"

    0番・1番はパソコンとの通信(書き込みやシリアルモニタ)と共通です。DFPlayerはSerial1(18番・19番)に繋ぎ、シリアルモニタと同時に使えるようにします。

!!! warning "RXには1kΩの抵抗を挟みます"

    DFPlayerの信号は3.3Vで動いていますが、Mega2560のTXからは5Vの信号が出ます。マイコンのTX1(18番)とDFPlayerのRXの間に **1kΩの抵抗** を入れて、DFPlayerに流れ込む電流を小さくします。抵抗がないと「ジー」というノイズが出ることがあります。

!!! warning "スピーカーはSPK_1・SPK_2に繋ぎます"

    SPK_1・SPK_2はDFPlayerの中のアンプを通した出力で、3Wまでのスピーカーを直接鳴らせます。DAC_R・DAC_Lはアンプを通っていない小さな信号なので、スピーカーを繋いでも音はほとんど聞こえません。

## microSDカードの準備

DFPlayerはmicroSDカードの中のファイルを **番号** で再生します。ファイル名は次のルールで付けます。

- microSDカードは **FAT32**(またはFAT16)でフォーマットする(32GBまで)
- microSDカードの一番上に **`mp3`という名前のフォルダ** を作る
- その中にファイルを **4桁の数字** の名前で入れる(`0001.mp3`、`0002.mp3`、…)

```
microSDカード
└── mp3
    ├── 0001.mp3
    ├── 0002.mp3
    └── 0003.mp3
```

こうしておくと、プログラムから「1番」と命令したときに`0001.mp3`が、「2番」と命令したときに`0002.mp3`が再生されます。

ファイル名が数字だけになり何の音かわからなくなるので、「1番は起動音」のように番号と音の対応をメモしておきましょう。

## 通信の速さ

DFPlayerの通信速度は **9600** に決まっています。シリアル通信の章で`Serial.begin(9600)`としたように、マイコン側のSerial1も9600に揃えます。

## 演習

DFPlayerを繋いだところ、次の配線になっていました。このままでは正しく動かない所が **2つ** あります。どこをどう直せばよいでしょうか。

| DFPlayerの端子 | 繋いだ先 |
| --- | --- |
| VCC | マイコンの5V |
| GND | マイコンのGND |
| RX | マイコンのRX1(19番) |
| TX | マイコンのTX1(18番) |
| DAC_R・DAC_L | スピーカー |

また、microSDカードの`mp3`フォルダに入れた`start.mp3`を「1番」として再生したいとき、ファイル名をどう変えればよいでしょうか。

??? tip "ヒントを見る"

    上の「端子の説明」の表と1行ずつ見くらべます。

    - RX・TXは「自分のTXを相手のRXに」繋ぎます。DFPlayerの **RX(受信)** に繋ぐのは、マイコンの **送信** する側です
    - スピーカーは「アンプ出力」の端子に繋ぎます

    ファイル名は「4桁の数字」のルールを見直しましょう。

??? success "答えを見る"

    **1. RXとTXが逆です。**

    - DFPlayerのRX → マイコンの **TX1(18番)**(間に1kΩの抵抗)
    - DFPlayerのTX → マイコンの **RX1(19番)**

    受信(RX)どうし・送信(TX)どうしを繋ぐと、マイコンの命令がDFPlayerに届きません。

    **2. スピーカーの繋ぎ先が違います。**

    スピーカーはDAC_R・DAC_Lではなく、**SPK_1・SPK_2** に繋ぎます。

    ファイル名は`start.mp3`を **`0001.mp3`** に変えます。4桁の数字の名前になっていないファイルは、番号で呼び出せません。
