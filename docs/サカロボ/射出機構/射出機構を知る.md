# 射出機構を知る

ロボットのモーター7つのうち、4つはタイヤに使いました。残りの **3つはボールを射出する機構** に使います。この章では、3つの射出用モーターを1つのボタンで動かせるようにします。

## モーターの繋ぎ方

[全体像を知る](../全体像を知る.md)の回路構成図を見ると、3つ目のモータードライバには3つのモーターが繋がっています。1つのモータードライバで別々に動かせるのはモーターAとモーターBの2つだけなので、**モーターBの出力に2つのモーターを並列に** 繋いでいます。

| モータードライバの出力 | 繋ぐモーター | マイコンから動かすピン |
| --- | --- | --- |
| モーターA(OUT1・OUT2) | 射出用モーター1 | ENA・IN1・IN2 |
| モーターB(OUT3・OUT4) | 射出用モーター2と射出用モーター3(並列) | ENB・IN3・IN4 |

**並列** とは、2つのモーターの線を、同じOUT3とOUT4に一緒に繋ぐ繋ぎ方です。

- OUT3 → モーター2の片方の線 **と** モーター3の片方の線
- OUT4 → モーター2のもう片方の線 **と** モーター3のもう片方の線

こうすると、2つのモーターには同じ電圧がかかり、**必ず一緒に回ります**。プログラムから見ると、モーター2とモーター3は「1つのモーター」のように扱えます。

## 並列に繋ぐときの注意

**1. 電流は2つ分流れます**

1つのモーターに最大0.3A流れるとすると、並列に繋いだモーターBの出力には **0.3A × 2 = 0.6A** 流れます。赤いモータードライバは1つの出力あたり2Aまでなので大丈夫ですが、モーターを増やしすぎると耐えられなくなります。

**2. 回る向きをそろえます**

2つのモーターの線を逆に繋ぐと、片方が正転、もう片方が逆転になります。先に1つずつ繋いで回る向きを確かめてから、同じ向きになるように並列に繋ぎましょう。

**3. 2つのモーターのばらつきはプログラムで直せません**

タイヤ制御の章では、`gain`でモーター1つ1つの速さをそろえました。並列の2つは同じ信号で動くので、片方だけ速さを変えることはできません。射出する力が左右で違うときは、ばらつきの小さい2つのモーターを選んで組み合わせます。

!!! warning "GNDとモーター電源は、ほかのモータードライバと共通にします"

    3つ目のモータードライバも、12V端子はモーター電源の+に、GNDはモーター電源の-とマイコンのGNDに繋ぎます。[モータードライバを知る](../モータードライバ/モータードライバを知る.md)の注意も見返してください。

## 演習

射出用モーターを3つ並列に繋ぎたくなりました。モーター1つに最大0.3A流れるとき、1つの出力に流れる電流は最大何Aになるでしょうか。また、赤いモータードライバの1つの出力で耐えられるでしょうか。

??? tip "ヒントを見る"

    並列に繋ぐと、モーターの数だけ電流が足し算されます。赤いモータードライバは1つの出力あたり **2A** まで流せます。

??? success "答えを見る"

    **0.3A × 3 = 0.9A** です。2Aより小さいので、電流だけを見れば耐えられます。

    ただし、モーターは回り始めるときや、ボールが詰まって回らなくなったときに、ふだんより大きな電流が流れます。L298Nは電流が大きいほど熱くなるので、並列に繋ぐモーターはなるべく少なくし、使っているときはモータードライバが熱くなりすぎていないか気を付けましょう(放熱板は熱くなるので、直接触るとやけどすることがあります)。
