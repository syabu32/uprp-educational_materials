# ボタンで射出する

3つの射出用モーターを、PS4コントローラーの **1つのボタン** で動かします。ボタンを押している間だけ3つのモーターが回り、離すと止まります。

`Motor`構造体は、[ばらつきを補正する](../タイヤ制御/ばらつきを補正する.md)で作った`gain`と`minSpeed`の入ったものをそのまま使います。ロボットのプログラムの中で`Motor`構造体を2種類作らないように、タイヤも射出機構も同じ構造体にそろえます。

```cpp
#include <PS4BT.h>
#include <usbhub.h>
#ifdef dobogusinclude
#include <spi4teensy3.h>
#endif
#include <SPI.h>

#define SHOOT_BUTTON R1   //射出に使うボタン
#define SHOOT_SPEED 255   //射出するときの速さ

struct Motor {
    int en;         //ENAを繋いだピン(PWM)
    int in1;        //IN1を繋いだピン
    int in2;        //IN2を繋いだピン
    float gain;     //速さの補正(一番遅いモーターは1.0、速いモーターは1.0より小さく)
    int minSpeed;   //動き始める速さ

    //ブレーキで止める
    void stop() {
        digitalWrite(in1, LOW);
        digitalWrite(in2, LOW);
        analogWrite(en, 255);
    }

    //ピンを出力モードにして、止まった状態から始める(setupで1回呼ぶ)
    void begin() {
        pinMode(en, OUTPUT);
        pinMode(in1, OUTPUT);
        pinMode(in2, OUTPUT);
        stop();
    }

    //speedが+なら正転、-なら逆転、0なら停止(-255〜255)
    void run(int speed) {
        if (speed > 255) {
            speed = 255;
        } else if (speed < -255) {
            speed = -255;
        }

        if (speed == 0) {
            stop();
            return;
        }

        //向きを決める
        if (speed > 0) {
            digitalWrite(in1, HIGH);
            digitalWrite(in2, LOW);
        } else {
            digitalWrite(in1, LOW);
            digitalWrite(in2, HIGH);
            speed = -speed;   //ここからは+の値で計算する
        }

        //補正した値をENAに出力する
        int output = minSpeed + speed * gain * (255 - minSpeed) / 255;
        analogWrite(en, output);
    }
};

USB Usb;
BTD Btd(&Usb);
PS4BT PS4(&Btd);

//{ENA, IN1, IN2, gain, minSpeed}
Motor shooterA = {11, 30, 31, 1.00, 0};   //射出用モーター1
Motor shooterB = {12, 32, 33, 1.00, 0};   //射出用モーター2・3(並列)

//射出用モーターを全部動かす(-255〜255)
void shoot(int speed) {
    shooterA.run(speed);
    shooterB.run(speed);
}

void setup() {
    Serial.begin(9600);
    shooterA.begin();
    shooterB.begin();

    if (Usb.Init() == -1) {
        Serial.println("USBホストシールドが見つかりません");
        while (true) {
        }
    }
    Serial.println("PS4コントローラーを待っています");
}

void loop() {
    Usb.Task();

    if (PS4.connected()) {
        if (PS4.getButtonPress(SHOOT_BUTTON)) {
            shoot(SHOOT_SPEED);
        } else {
            shoot(0);
        }
    } else {
        shoot(0);
    }
}
```

このコードはシリアルモニタに次のように出力されます。R1を押している間だけ、3つの射出用モーターが回ります。

```
PS4コントローラーを待っています
```

!!! warning "ピン番号は例です"

    `shooterA`・`shooterB`のピン番号は、タイヤに使った5〜8番・22〜29番と重ならないように選んだ例です。実際のピンは、このあとの「ロボットを完成させる」の章で自分で決めます。

## 3つのモーターを2つの実物で動かす

モーター2とモーター3はモーターBの出力に並列に繋がっているので、プログラムでは`shooterB`の **1つの実物** で2つとも動きます。

| 実物 | 動くモーター |
| --- | --- |
| `shooterA` | 射出用モーター1 |
| `shooterB` | 射出用モーター2・3 |

`shoot()`は、タイヤ制御の章の`tankDrive()`と同じ考え方で、射出用の実物をまとめて動かす関数です。`loop()`からは`shoot(SHOOT_SPEED)`と`shoot(0)`を呼ぶだけで、3つのモーターのことを考えずに済みます。

`minSpeed`を0にしているのは、射出機構は全速(255)で回すことが多く、小さい速さで使わないためです。射出用モーター1と、モーター2・3の組で速さが違うときは、タイヤと同じように`gain`で合わせます。

## ボタンと速さに名前を付ける

```cpp
#define SHOOT_BUTTON R1   //射出に使うボタン
#define SHOOT_SPEED 255   //射出するときの速さ
```

ボタンの名前(`R1`など)も`#define`で名前を付けられます。使うボタンを変えたいときや、ボールが飛びすぎるので速さを下げたいときは、この2行を書き換えるだけで済みます。

## 押していないときも、切れたときも止める

`if (PS4.getButtonPress(SHOOT_BUTTON))`の`else`で`shoot(0)`を呼んでいます。これがないと、一度R1を押したあと **離してもモーターが回り続けます**。`run()`は「次の命令が来るまで同じ速さで回し続ける」からです。

コントローラーが切れたときの`else`でも`shoot(0)`を呼んでいます。タイヤと同じく、操作できない状態でモーターを回し続けないようにします。

## 演習

射出を **トグル** に変えてください。R1を1回押すと3つのモーターが回り続け、もう1回押すと止まるようにします。コントローラーが切れたときは、トグルの状態に関係なく止めます。

??? tip "ヒントを見る"

    ボタンの章のトグルの作り方と同じです。

    | やること | 書き方 |
    | --- | --- |
    | 1. トグルの状態を覚える変数を作る | `loop()`の外に`bool isShooting = false;` |
    | 2. 押すたびに切り替える | `if (PS4.getButtonClick(SHOOT_BUTTON))`の中で`isShooting = !isShooting;` |
    | 3. ONなら回す、OFFなら止める | `if (isShooting)`の中で`shoot(SHOOT_SPEED);`、`else`で`shoot(0);` |

    トグルには`getButtonPress()`ではなく`getButtonClick()`を使います。

??? success "答えを見る"

    変わるのは`loop()`と、その上に追加する変数だけなので、そこだけ示します。

    ```cpp
    bool isShooting = false;   //射出のトグルの状態

    void loop() {
        Usb.Task();

        if (PS4.connected()) {
            if (PS4.getButtonClick(SHOOT_BUTTON)) {
                isShooting = !isShooting;
            }

            if (isShooting) {
                shoot(SHOOT_SPEED);
            } else {
                shoot(0);
            }
        } else {
            shoot(0);
        }
    }
    ```

    コントローラーが切れたときは`shoot(0)`で止まりますが、`isShooting`は`true`のまま残ります。繋がり直すとまた回り出すので、それが困るときは`else`の中に`isShooting = false;`も書き足しましょう。

## 脳内実行してみよう

最初のプログラム(押している間だけ回す方)で、`loop()`が次の順に4周しました。それぞれの周が終わったとき、`shooterB`のENA(12番)に出力されている値はいくつでしょうか。

| 周 | コントローラー | R1 |
| --- | --- | --- |
| 1 | 繋がっている | 押していない |
| 2 | 繋がっている | 押している |
| 3 | 繋がっていない | 押している |
| 4 | 繋がっている | 押している |

??? success "答えを見る"

    | 周 | 通る場所 | 呼ばれる関数 | ENA(12番) |
    | --- | --- | --- | --- |
    | 1 | `connected()`は`true`、`getButtonPress()`は`false` | `shoot(0)` → `stop()` | **255**(ブレーキ) |
    | 2 | `connected()`は`true`、`getButtonPress()`は`true` | `shoot(255)` | **255**(全速で正転) |
    | 3 | `connected()`は`false` | `shoot(0)` → `stop()` | **255**(ブレーキ) |
    | 4 | `connected()`は`true`、`getButtonPress()`は`true` | `shoot(255)` | **255**(全速で正転) |

    ENAはどの周も255ですが、意味が違います。`stop()`はIN3・IN4を両方LOWにしてENAを255にする **ブレーキ**、`shoot(255)`はIN3をHIGH、IN4をLOWにしてENAを255にする **全速の正転** です。ENAだけを見ても動きはわからないので、**IN1・IN2(IN3・IN4)と一緒に** 確かめましょう。

    `shoot(255)`の中の計算は、`minSpeed`が0、`gain`が1.00なので`0 + 255 × 1.00 × 255 ÷ 255 = 255`です。

    3周目はR1を押していても、コントローラーが繋がっていないので`else`の`shoot(0)`が呼ばれます。
