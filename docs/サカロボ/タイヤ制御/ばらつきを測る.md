# ばらつきを測る

`tankDrive(200, 200)`でまっすぐ進むはずなのに、ロボットが少しずつ右や左に曲がってしまうことがあります。原因の多くは **モーターの性能のばらつき** です。

同じ種類のモーターでも、1つ1つ少しずつ性能が違います。

- **回る速さのばらつき**: 同じ`run(200)`でも、速く回るモーターと遅く回るモーターがある
- **動き始める速さのばらつき**: `run(40)`で回るモーターもあれば、`run(70)`にしないと回らないモーターもある

左側のモーターが右側より少し速いと、ロボットは右に曲がっていきます。プログラムでこのばらつきを直すために、まずは4つのモーターを1つずつ測ります。

## 測る準備

- ロボットを台の上に置いて、**タイヤが床から浮いた状態** にします
- 4つのタイヤの横に、ビニールテープで **目印** を付けます
- 測るモーターは`Motor testMotor = {5, 22, 23};`のピン番号を書き換えて、1つずつ選びます

## 動き始める速さを測る

速さを0から5ずつ上げながら、シリアルモニタに今の速さを表示します。タイヤが **回り始めたときの速さ** を記録します。

```cpp
struct Motor {
    int en;    //ENAを繋いだピン(PWM)
    int in1;   //IN1を繋いだピン
    int in2;   //IN2を繋いだピン

    //ブレーキで止める
    void stop() {
        digitalWrite(in1, LOW);
        digitalWrite(in2, LOW);
        analogWrite(en, 255);
    }

    //ピンを出力モードにして、止まった状態から始める(setupで1回呼ぶ)
    void begin() {
        pinMode(en, OUTPUT);
        pinMode(in1, OUTPUT);
        pinMode(in2, OUTPUT);
        stop();
    }

    //speedが+なら正転、-なら逆転、0なら停止(-255〜255)
    void run(int speed) {
        if (speed > 255) {
            speed = 255;
        } else if (speed < -255) {
            speed = -255;
        }

        if (speed > 0) {
            digitalWrite(in1, HIGH);
            digitalWrite(in2, LOW);
            analogWrite(en, speed);
        } else if (speed < 0) {
            digitalWrite(in1, LOW);
            digitalWrite(in2, HIGH);
            analogWrite(en, -speed);   //analogWriteには+の値を渡す
        } else {
            stop();
        }
    }
};

Motor testMotor = {5, 22, 23};   //測るモーターのピンに書き換える

void setup() {
    Serial.begin(9600);
    testMotor.begin();

    for (int speed = 0; speed <= 150; speed += 5) {
        testMotor.run(speed);
        Serial.print("速さ: ");
        Serial.println(speed);
        delay(1000);
    }

    testMotor.stop();
    Serial.println("終わり");
}

void loop() {
}
```

このコードは次のように出力されます。

```
速さ: 0
速さ: 5
速さ: 10
.
.
.
速さ: 145
速さ: 150
終わり
```

表示を見ながらタイヤを見て、「速さ: 55」でタイヤが回り始めたら、そのモーターの動き始める速さは **55** です。モーターは一度回り出すと小さい速さでも回り続けるので、**止まった状態から回り始めた値** を記録します。

## 回る速さを測る

同じ速さで10秒間回して、その間にタイヤが何回転したかを数えます。目印が上に来た回数を数えましょう。

```cpp
//Motor構造体は上と同じ

Motor testMotor = {5, 22, 23};   //測るモーターのピンに書き換える

void setup() {
    Serial.begin(9600);
    testMotor.begin();

    Serial.println("3秒後にスタート");
    delay(3000);

    testMotor.run(200);
    Serial.println("スタート");
    delay(10000);

    testMotor.stop();
    Serial.println("ストップ");
}

void loop() {
}
```

このコードは次のように出力されます。

```
3秒後にスタート
スタート
ストップ
```

回転数が少ない場合は、1回転の途中まで(半分なら0.5回転)数えると、より正確になります。

## 測った結果を表にまとめる

4つのモーターを測ったら、次のような表にまとめます。

| モーター | 動き始める速さ | 10秒間の回転数(`run(200)`) |
| --- | --- | --- |
| 左前 | 50 | 42 |
| 左後ろ | 60 | 40 |
| 右前 | 55 | 38 |
| 右後ろ | 45 | 41 |

この例では、次のことがわかります。

- **一番遅いのは右前**(38回転)です。ほかのモーターは右前より速く回っています
- **一番動き始めにくいのは左後ろ**(60)です。速さが60より小さいと、左後ろだけが回りません

このままだと、左側(42と40)の方が右側(38と41)より速いので、ロボットは右に曲がっていきます。次の章では、この表を使ってばらつきを直します。

!!! warning "電池の減り方でも速さは変わります"

    モーターの速さは、モーター電源の電池が減ると遅くなります。4つのモーターは **同じ電池の状態で続けて** 測りましょう。

## 演習

次の表は、あるロボットの4つのモーターを測った結果です。**一番遅いモーター** と、**一番動き始めにくいモーター** はそれぞれどれでしょうか。また、このロボットに`tankDrive(200, 200)`を渡すと、左右どちらに曲がっていくでしょうか。

| モーター | 動き始める速さ | 10秒間の回転数(`run(200)`) |
| --- | --- | --- |
| 左前 | 40 | 35 |
| 左後ろ | 45 | 36 |
| 右前 | 65 | 40 |
| 右後ろ | 50 | 39 |

??? tip "ヒントを見る"

    | 知りたいこと | 表のどこを見るか |
    | --- | --- |
    | 一番遅いモーター | 「回転数」が **一番小さい** 行 |
    | 一番動き始めにくいモーター | 「動き始める速さ」が **一番大きい** 行 |
    | 曲がる向き | 左側2つと右側2つの回転数をくらべる。**遅い側** に曲がる |

??? success "答えを見る"

    - 一番遅いモーターは **左前**(35回転)
    - 一番動き始めにくいモーターは **右前**(65)
    - 左側(35と36)の方が右側(40と39)より遅いので、ロボットは **左** に曲がっていきます

    戦車のように動くロボットは、速い側が遅い側を追い越すように進むので、**遅い側に向かって** 曲がります。

## 脳内実行してみよう

「動き始める速さを測る」のプログラムで、`for`の行を次のように書き換えました。シリアルモニタに表示される速さを全部書き出してください。また、動き始める速さが **47** のモーターは、どの速さのときに初めて回り始めるでしょうか。

```cpp
for (int speed = 30; speed <= 60; speed += 10) {
```

??? success "答えを見る"

    ```
    速さ: 30
    速さ: 40
    速さ: 50
    速さ: 60
    終わり
    ```

    | `speed` | 47以上? | タイヤ |
    | --- | --- | --- |
    | 30 | いいえ | 回らない |
    | 40 | いいえ | 回らない |
    | 50 | はい | **回り始める** |
    | 60 | はい | 回る |

    **速さ50** で初めて回り始めます。ただし、このプログラムでは「40では回らず50で回った」ことしかわからないので、本当の値が41〜50のどれなのかは区別できません。10ずつ増やすと速く測れますが、細かくはわからなくなります。正確に測りたいときは、増やす幅を小さくしましょう。
