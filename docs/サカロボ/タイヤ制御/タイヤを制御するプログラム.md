# タイヤを制御するプログラム

この章のまとめとして、補正を入れた`Motor`と`tankDrive()`を、PS4コントローラーの章のプログラムに組み込みます。操作はPS4コントローラーの章と同じです。

- **左スティックの上下**: 前進・後退
- **右スティックの左右**: 左回転・右回転
- スティックは **しきい値以上** 傾けたときだけ動く
- コントローラーが切れたら全部のモーターを止める

```cpp
#include <PS4BT.h>
#include <usbhub.h>
#ifdef dobogusinclude
#include <spi4teensy3.h>
#endif
#include <SPI.h>

#define STICK_THRESHOLD 20   //スティックのしきい値

struct Motor {
    int en;         //ENAを繋いだピン(PWM)
    int in1;        //IN1を繋いだピン
    int in2;        //IN2を繋いだピン
    float gain;     //速さの補正(一番遅いモーターは1.0、速いモーターは1.0より小さく)
    int minSpeed;   //動き始める速さ

    //ブレーキで止める
    void stop() {
        digitalWrite(in1, LOW);
        digitalWrite(in2, LOW);
        analogWrite(en, 255);
    }

    //ピンを出力モードにして、止まった状態から始める(setupで1回呼ぶ)
    void begin() {
        pinMode(en, OUTPUT);
        pinMode(in1, OUTPUT);
        pinMode(in2, OUTPUT);
        stop();
    }

    //speedが+なら正転、-なら逆転、0なら停止(-255〜255)
    void run(int speed) {
        if (speed > 255) {
            speed = 255;
        } else if (speed < -255) {
            speed = -255;
        }

        if (speed == 0) {
            stop();
            return;
        }

        //向きを決める
        if (speed > 0) {
            digitalWrite(in1, HIGH);
            digitalWrite(in2, LOW);
        } else {
            digitalWrite(in1, LOW);
            digitalWrite(in2, HIGH);
            speed = -speed;   //ここからは+の値で計算する
        }

        //補正した値をENAに出力する
        int output = minSpeed + speed * gain * (255 - minSpeed) / 255;
        analogWrite(en, output);
    }
};

USB Usb;
BTD Btd(&Usb);
PS4BT PS4(&Btd);

//{ENA, IN1, IN2, gain, minSpeed}
Motor leftFront = {5, 22, 23, 0.90, 50};    //左前
Motor leftBack = {6, 24, 25, 0.95, 60};     //左後ろ
Motor rightFront = {7, 26, 27, 1.00, 55};   //右前
Motor rightBack = {8, 28, 29, 0.93, 45};    //右後ろ

bool isSquareOn = false;   //□のトグルの状態

//左側と右側の速さを決めて動かす(-255〜255)
void tankDrive(int leftSpeed, int rightSpeed) {
    leftFront.run(leftSpeed);
    leftBack.run(leftSpeed);
    rightFront.run(rightSpeed);
    rightBack.run(rightSpeed);
}

//真ん中を0にした値を受け取り、しきい値より小さければ0にする
int applyThreshold(int value) {
    if (value < STICK_THRESHOLD && value > -STICK_THRESHOLD) {
        return 0;
    }
    return value;
}

//スティックでロボットを動かす
void drive() {
    int forward = applyThreshold(127 - PS4.getAnalogHat(LeftHatY)) * 2;   //前後(上が+)
    int turn = applyThreshold(PS4.getAnalogHat(RightHatX) - 127) * 2;     //回転(右が+)

    tankDrive(forward + turn, forward - turn);
}

//ボタンを読み取る
void readButtons() {
    //押している間
    if (PS4.getButtonPress(CIRCLE)) {
        //ここに○を押している間の処理を書く
    }

    //押した1回だけ
    if (PS4.getButtonClick(TRIANGLE)) {
        Serial.println("△");
        //ここに△を押したときの処理を書く
    }

    //トグル
    if (PS4.getButtonClick(SQUARE)) {
        isSquareOn = !isSquareOn;
        if (isSquareOn) {
            Serial.println("□: ON");
        } else {
            Serial.println("□: OFF");
        }
    }
    if (isSquareOn) {
        //ここに□がONの間の処理を書く
    }
}

void setup() {
    Serial.begin(9600);

    leftFront.begin();
    leftBack.begin();
    rightFront.begin();
    rightBack.begin();

    #if !defined(__MIPSEL__)
        while (!Serial);
    #endif
        if (Usb.Init() == -1) {
            Serial.print("USBホストシールドが見つかりません");
            while (1);
        }
        Serial.println("PS4コントローラーを待っています");
}

void loop() {
    Usb.Task();

    if (PS4.connected()) {
        drive();
        readButtons();
    } else {
        tankDrive(0, 0);
    }
}
```

コントローラーを繋いで「△ → □ → □」の順に押すと、次のように出力されます。

```
PS4コントローラーを待っています
△
□: ON
□: OFF
```

## PS4コントローラーの章から変わった所

| 場所 | PS4コントローラーの章 | この章 |
| --- | --- | --- |
| `Motor` | ピン3つだけ | `gain`と`minSpeed`を追加して、`run()`の中で補正する |
| モーターを動かす | `drive()`の中で4つの`run()`を呼ぶ | `tankDrive()`にまとめた |
| 止める | `stopAll()` | `tankDrive(0, 0)` |

`drive()`は「スティックから左右の速さを計算する」だけ、`tankDrive()`は「左右の速さを4つのタイヤに渡す」だけ、`run()`は「1つのモーターを補正して動かす」だけ、と役割を分けています。そのため、補正の値を変えるときは`Motor`の行だけ、操作を変えるときは`drive()`だけを書き換えれば済みます。

## 走らせて仕上げる

前の章の`gain`はタイヤを浮かせて測った値なので、床の上ではロボットの重さや床の滑りやすさで少しずれます。最後に、実際に床を走らせて調整します。

1. 床にまっすぐテープを貼り、その上にロボットを置きます
2. 左スティックだけを **上いっぱい** に倒して、3mくらい走らせます
3. テープからどちらにずれたかを見て、下の表の通りに`gain`を少し(0.02くらい)変えます
4. まっすぐ走るまで2〜3をくり返します

| ずれた向き | 原因 | 直し方 |
| --- | --- | --- |
| 右にずれた | 左側が速い | **左側** の2つの`gain`を少し下げる |
| 左にずれた | 右側が速い | **右側** の2つの`gain`を少し下げる |
| まっすぐ | – | そのまま |

速さをゆっくり(左スティックを半分くらい)にしても同じように試し、どちらもだいたいまっすぐになれば完成です。

!!! warning "`gain`は下げる方向だけで調整します"

    `gain`を1.00より大きくすると、`run(255)`のときにENAへの出力が255を超えてしまいます。遅い側を上げるのではなく、**速い側を下げて** 合わせましょう。

## 演習

補正したロボットを床で走らせると、**左にずれて** いきました。今の`Motor`の行は上のプログラムの通りです。どの`Motor`の`gain`をどう変えればよいでしょうか。0.02ずつ変えるとして、書き換えた行を答えてください。

??? tip "ヒントを見る"

    | 考えること | 答えの出し方 |
    | --- | --- |
    | 1. 左にずれたのは、どちらの側が速いから? | 「走らせて仕上げる」の表を見る |
    | 2. 速い側のモーターはどれ? | 左側なら`leftFront`・`leftBack`、右側なら`rightFront`・`rightBack` |
    | 3. `gain`を上げる? 下げる? | 速い側を **下げる** |

    `gain`を変えるのは **同じ側の2つとも** です。1つだけ変えると、前と後ろのタイヤの速さがそろわなくなります。

??? success "答えを見る"

    左にずれたのは **右側が速い** からなので、右側の2つの`gain`を0.02下げます。

    ```cpp
    //{ENA, IN1, IN2, gain, minSpeed}
    Motor leftFront = {5, 22, 23, 0.90, 50};    //左前
    Motor leftBack = {6, 24, 25, 0.95, 60};     //左後ろ
    Motor rightFront = {7, 26, 27, 0.98, 55};   //右前
    Motor rightBack = {8, 28, 29, 0.91, 45};    //右後ろ
    ```

    `rightFront`は1.00 → **0.98**、`rightBack`は0.93 → **0.91** です。左側の2つは変えません。

## 脳内実行してみよう

上のプログラムで、`getAnalogHat(LeftHatY)`が **0**(上いっぱい)、`getAnalogHat(RightHatX)`が **127**(触らない)のとき、`leftFront`と`rightFront`のENAにはそれぞれいくつが出力されるでしょうか。

??? success "答えを見る"

    `leftFront`のENAは **233**、`rightFront`のENAは **254** です。

    まず`drive()`の中です。

    | 計算 | 値 |
    | --- | --- |
    | `127 - 0` | 127 |
    | `applyThreshold(127) * 2` | `forward` = 254 |
    | `127 - 127` | 0 |
    | `applyThreshold(0) * 2` | `turn` = 0 |
    | `tankDrive(254 + 0, 254 - 0)` | 左右とも254 |

    次に、それぞれの`run(254)`の中です。

    | 計算 | `leftFront`(0.90, 50) | `rightFront`(1.00, 55) |
    | --- | --- | --- |
    | `speed * gain` | 254 × 0.90 = 228.6 | 254 × 1.00 = 254 |
    | `× (255 - minSpeed)` | 228.6 × 205 = 46863 | 254 × 200 = 50800 |
    | `÷ 255` | 183.78… | 199.21… |
    | `minSpeed + ` | 50 + 183.78… = 233.78… | 55 + 199.21… = 254.21… |
    | `int output` | **233** | **254** |

    どちらも同じ254を渡していますが、補正によって速い`leftFront`の方が小さい値になっています。
