# ばらつきを補正する

前の章で測った表を使って、モーターのばらつきをプログラムで直します。これを **補正** といいます。

補正のやり方は2つです。

- **速いモーターを遅いモーターに合わせる**: 速いモーターだけ、少し遅くなるように速さを減らす
- **小さい速さでも必ず回るようにする**: 動き始める速さより小さい値をENAに出さない

この2つを`Motor`構造体に組み込むと、`tankDrive()`や`run()`の使い方を変えずに、全部のモーターがそろって回るようになります。

```cpp
struct Motor {
    int en;         //ENAを繋いだピン(PWM)
    int in1;        //IN1を繋いだピン
    int in2;        //IN2を繋いだピン
    float gain;     //速さの補正(一番遅いモーターは1.0、速いモーターは1.0より小さく)
    int minSpeed;   //動き始める速さ

    //ブレーキで止める
    void stop() {
        digitalWrite(in1, LOW);
        digitalWrite(in2, LOW);
        analogWrite(en, 255);
    }

    //ピンを出力モードにして、止まった状態から始める(setupで1回呼ぶ)
    void begin() {
        pinMode(en, OUTPUT);
        pinMode(in1, OUTPUT);
        pinMode(in2, OUTPUT);
        stop();
    }

    //speedが+なら正転、-なら逆転、0なら停止(-255〜255)
    void run(int speed) {
        if (speed > 255) {
            speed = 255;
        } else if (speed < -255) {
            speed = -255;
        }

        if (speed == 0) {
            stop();
            return;
        }

        //向きを決める
        if (speed > 0) {
            digitalWrite(in1, HIGH);
            digitalWrite(in2, LOW);
        } else {
            digitalWrite(in1, LOW);
            digitalWrite(in2, HIGH);
            speed = -speed;   //ここからは+の値で計算する
        }

        //補正した値をENAに出力する
        int output = minSpeed + speed * gain * (255 - minSpeed) / 255;
        analogWrite(en, output);
    }
};

//{ENA, IN1, IN2, gain, minSpeed}
Motor leftFront = {5, 22, 23, 0.90, 50};    //左前
Motor leftBack = {6, 24, 25, 0.95, 60};     //左後ろ
Motor rightFront = {7, 26, 27, 1.00, 55};   //右前
Motor rightBack = {8, 28, 29, 0.93, 45};    //右後ろ

//左側と右側の速さを決めて動かす(-255〜255)
void tankDrive(int leftSpeed, int rightSpeed) {
    leftFront.run(leftSpeed);
    leftBack.run(leftSpeed);
    rightFront.run(rightSpeed);
    rightBack.run(rightSpeed);
}

void setup() {
    Serial.begin(9600);
    leftFront.begin();
    leftBack.begin();
    rightFront.begin();
    rightBack.begin();

    tankDrive(200, 200);
    Serial.println("前進");
    delay(3000);

    tankDrive(0, 0);
    Serial.println("停止");
}

void loop() {
}
```

このコードは次のように出力されます。

```
前進
停止
```

`gain`と`minSpeed`の値は、前の章の表の例から決めたものです。自分のロボットで測った値に書き換えてください。

## gainの決め方

`gain`は「このモーターを何倍の速さにするか」です。**一番遅いモーターの回転数 ÷ そのモーターの回転数** で計算します。

| モーター | 10秒間の回転数 | 計算 | `gain` |
| --- | --- | --- | --- |
| 左前 | 42 | 38 ÷ 42 = 0.904… | 0.90 |
| 左後ろ | 40 | 38 ÷ 40 = 0.95 | 0.95 |
| 右前 | 38(一番遅い) | 38 ÷ 38 = 1 | 1.00 |
| 右後ろ | 41 | 38 ÷ 41 = 0.926… | 0.93 |

一番遅いモーターは`gain`が1.00になり、それより速いモーターは1.00より小さくなります。速いモーターを遅いモーターに合わせるので、全速(255)を出せるのは一番遅いモーターだけになりますが、そのかわり4つがそろって回ります。

遅いモーターを速くする(1.00より大きくする)ことはできません。一番遅いモーターはもう全速で回っているかもしれないからです。

## minSpeedの決め方

`minSpeed`には、前の章で測った **動き始める速さ** をそのまま入れます。

## run()の中の計算

補正の計算はこの1行です。

```cpp
int output = minSpeed + speed * gain * (255 - minSpeed) / 255;
```

2つのことを1行でしています。

**1. 速さを`gain`倍する**

`speed * gain`で、速いモーターほど少し遅くします。

**2. 0〜255を「minSpeed〜255」に縮める**

`speed`が1でも必ず`minSpeed`以上になるように、使う範囲を縮めます。

| `speed` | `minSpeed`=55、`gain`=1.00のときの`output` |
| --- | --- |
| 1 | 55(動き始める速さ) |
| 100 | 133 |
| 200 | 211 |
| 255 | 255(全速) |

これで、`run(1)`のような小さい速さでも「回らない」ことがなくなります。

`gain`が`float`型(小数)なので、計算の途中は小数になります。最後に`int`型の`output`に入れるときに、**小数点以下は切り捨て** られます。

!!! warning "補正は「だいたい」合わせるものです"

    `gain`は`run(200)`で測った回転数から計算しているので、ほかの速さでは少しずれることがあります。次の章で、実際にロボットを走らせながら仕上げの調整をします。

## 補正した結果

上のプログラムで`tankDrive(200, 200)`を渡したときの、ENAへの出力です。

| モーター | `gain` | `minSpeed` | ENAへの出力 |
| --- | --- | --- | --- |
| 左前 | 0.90 | 50 | 194 |
| 左後ろ | 0.95 | 60 | 205 |
| 右前 | 1.00 | 55 | 211 |
| 右後ろ | 0.93 | 45 | 198 |

同じ200を渡しても、モーターごとにENAへの出力が変わります。出力はバラバラですが、**実際に回る速さがそろう** ように調整されています。

## 演習

前の章の演習の表を測ったロボットで、4つのモーターの`Motor`の行を書いてください。ピン番号は上のプログラムと同じにして、`gain`は小数第2位までにします(第3位を四捨五入)。

| モーター | 動き始める速さ | 10秒間の回転数(`run(200)`) |
| --- | --- | --- |
| 左前 | 40 | 35 |
| 左後ろ | 45 | 36 |
| 右前 | 65 | 40 |
| 右後ろ | 50 | 39 |

??? tip "ヒントを見る"

    | やること | どうするか |
    | --- | --- |
    | 1. 一番遅いモーターを探す | 回転数が一番小さい行 |
    | 2. それぞれの`gain`を計算する | 一番遅いモーターの回転数 ÷ そのモーターの回転数 |
    | 3. 小数第2位までにする | 例: 0.8974… → 0.90 |
    | 4. `minSpeed`を入れる | 「動き始める速さ」をそのまま |
    | 5. `Motor`の行を書く | `{ENA, IN1, IN2, gain, minSpeed}`の順 |

??? success "答えを見る"

    一番遅いのは左前の35回転です。

    | モーター | 計算 | `gain` | `minSpeed` |
    | --- | --- | --- | --- |
    | 左前 | 35 ÷ 35 = 1 | 1.00 | 40 |
    | 左後ろ | 35 ÷ 36 = 0.972… | 0.97 | 45 |
    | 右前 | 35 ÷ 40 = 0.875 | 0.88 | 65 |
    | 右後ろ | 35 ÷ 39 = 0.897… | 0.90 | 50 |

## 脳内実行してみよう

`gain`が **0.90**、`minSpeed`が **60** のモーターに`run(-100)`を渡しました。IN1・IN2・ENAはそれぞれどうなるでしょうか。

??? success "答えを見る"

    IN1は **LOW**、IN2は **HIGH**、ENAは **128** です。

    | 実行する行 | `speed` | 何が起きるか |
    | --- | --- | --- |
    | `if (speed > 255)`など | -100 | 範囲の中なので何もしない |
    | `if (speed == 0)` | -100 | 違うので次へ |
    | `if (speed > 0)` | -100 | 違うので`else`へ |
    | `digitalWrite(in1, LOW);`・`digitalWrite(in2, HIGH);` | -100 | 逆転の向きにする |
    | `speed = -speed;` | 100 | +の値にする |
    | `100 * 0.90` | 100 | 90 |
    | `90 * (255 - 60)` | 100 | 90 × 195 = 17550 |
    | `17550 / 255` | 100 | 68.82… |
    | `60 + 68.82…` | 100 | 128.82… |
    | `int output = 128.82…` | 100 | 小数点以下が切り捨てられて **128** |

    `return`は、関数の章で学んだように **そこで関数を終わらせる** ためにも使えます。`speed`が0のときは`stop()`したあと、下の計算をせずに`run()`を抜けます。
