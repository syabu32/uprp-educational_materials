# タイヤを動かす

PS4コントローラーの章で、とりあえずロボットを動かせるようになりました。この章では、タイヤの動かし方を整理して、**まっすぐ走る・思った通りに曲がる** ロボットにしていきます。

サカロボは左右に2つずつ、合わせて4つのタイヤが付いています。ハンドルで向きを変えるタイヤはないので、戦車と同じように **左側と右側の速さを変えて** 曲がります。

## 左側と右側に分けて考える

4つのタイヤを別々に考えると大変なので、「左側」と「右側」の2つにまとめます。同じ側の前と後ろのタイヤには、**必ず同じ速さ** を渡します。

```cpp
struct Motor {
    int en;    //ENAを繋いだピン(PWM)
    int in1;   //IN1を繋いだピン
    int in2;   //IN2を繋いだピン

    //ブレーキで止める
    void stop() {
        digitalWrite(in1, LOW);
        digitalWrite(in2, LOW);
        analogWrite(en, 255);
    }

    //ピンを出力モードにして、止まった状態から始める(setupで1回呼ぶ)
    void begin() {
        pinMode(en, OUTPUT);
        pinMode(in1, OUTPUT);
        pinMode(in2, OUTPUT);
        stop();
    }

    //speedが+なら正転、-なら逆転、0なら停止(-255〜255)
    void run(int speed) {
        if (speed > 255) {
            speed = 255;
        } else if (speed < -255) {
            speed = -255;
        }

        if (speed > 0) {
            digitalWrite(in1, HIGH);
            digitalWrite(in2, LOW);
            analogWrite(en, speed);
        } else if (speed < 0) {
            digitalWrite(in1, LOW);
            digitalWrite(in2, HIGH);
            analogWrite(en, -speed);   //analogWriteには+の値を渡す
        } else {
            stop();
        }
    }
};

Motor leftFront = {5, 22, 23};    //左前
Motor leftBack = {6, 24, 25};     //左後ろ
Motor rightFront = {7, 26, 27};   //右前
Motor rightBack = {8, 28, 29};    //右後ろ

//左側と右側の速さを決めて動かす(-255〜255)
void tankDrive(int leftSpeed, int rightSpeed) {
    leftFront.run(leftSpeed);
    leftBack.run(leftSpeed);
    rightFront.run(rightSpeed);
    rightBack.run(rightSpeed);
}

void setup() {
    Serial.begin(9600);
    leftFront.begin();
    leftBack.begin();
    rightFront.begin();
    rightBack.begin();
}

void loop() {
    tankDrive(200, 200);
    Serial.println("前進");
    delay(2000);

    tankDrive(200, -200);
    Serial.println("その場で右回転");
    delay(1000);

    tankDrive(200, 100);
    Serial.println("右に曲がりながら前進");
    delay(2000);

    tankDrive(0, 0);
    Serial.println("停止");
    delay(1000);
}
```

このコードは次のように出力されます。

```
前進
その場で右回転
右に曲がりながら前進
停止
.
.
.
```

## 左右の速さと動き

| 左側 | 右側 | ロボットの動き |
| --- | --- | --- |
| + | +(左と同じ) | 前進 |
| - | -(左と同じ) | 後退 |
| + | - | その場で右回転 |
| - | + | その場で左回転 |
| +(大きい) | +(小さい) | 右に曲がりながら前進 |
| +(小さい) | +(大きい) | 左に曲がりながら前進 |
| 0 | 0 | 停止 |

左右の速さの **差が大きいほど急に** 曲がります。左右が同じ速さで逆向きのときは、ロボットの真ん中を中心にその場で回ります。

## タイヤは滑りながら曲がる

曲がるとき、タイヤは進む向きとは違う向きに **横に滑りながら** 回っています。そのため、床によって曲がりやすさが変わります。

- ツルツルした床: よく滑るので、曲がりやすい
- ゴムマットのような滑りにくい床: 曲がりにくく、モーターに大きな力がかかる

!!! warning "同じ側の前と後ろに違う速さを渡さないでください"

    左前が200、左後ろが100のように同じ側で速さが違うと、2つのタイヤが床の上で引っ張り合います。ロボットはまっすぐ進まず、モーターやモータードライバに余計な負担がかかります。`tankDrive()`を使えば、同じ側には必ず同じ速さが渡されます。

## 取り付けの向きに気を付ける

左側と右側のモーターは、ロボットに **向かい合わせ** に取り付けることが多いです。そのため、同じ`run(200)`でも、左は前に、右は後ろに回ることがあります。

`tankDrive(200, 200)`で前進しないタイヤがあったら、そのモーターのOUT1とOUT2の線を入れ替えて、**全部のタイヤが`+`で前に進む** ようにそろえてからプログラムを作りましょう。

## 演習

`tankDrive()`を使って、ロボットが「前進(速さ180)2秒 → その場で左回転(速さ150)1秒 → 後退(速さ180)2秒 → 停止1秒」を繰り返すように`loop()`を書き換えてください。

??? tip "ヒントを見る"

    「左右の速さと動き」の表から、動きごとに左側と右側の符号を選びます。

    | 動き | 左側 | 右側 | 書き方 |
    | --- | --- | --- | --- |
    | 前進 | + | + | `tankDrive(180, 180);` |
    | その場で左回転 | - | + | `tankDrive(-150, 150);` |
    | 後退 | - | - | `tankDrive(-180, -180);` |
    | 停止 | 0 | 0 | `tankDrive(0, 0);` |

??? success "答えを見る"

    `Motor`・`tankDrive()`・`setup()`は上のコードと同じなので、`loop()`だけ示します。

    ```cpp
    void loop() {
        tankDrive(180, 180);
        Serial.println("前進");
        delay(2000);

        tankDrive(-150, 150);
        Serial.println("その場で左回転");
        delay(1000);

        tankDrive(-180, -180);
        Serial.println("後退");
        delay(2000);

        tankDrive(0, 0);
        Serial.println("停止");
        delay(1000);
    }
    ```

    出力は次のようになります。

    ```
    前進
    その場で左回転
    後退
    停止
    .
    .
    .
    ```

## 脳内実行してみよう

上のプログラムの`setup()`の最後で、次の1行を実行しました。4つのモーターのIN1・ENAはそれぞれどうなり、ロボットはどう動くでしょうか。

```cpp
tankDrive(-100, 300);
```

??? success "答えを見る"

    | モーター | `run()`に渡す値 | IN1 | ENA |
    | --- | --- | --- | --- |
    | `leftFront` | -100 | LOW | 100 |
    | `leftBack` | -100 | LOW | 100 |
    | `rightFront` | 300 → 255に直る | HIGH | 255 |
    | `rightBack` | 300 → 255に直る | HIGH | 255 |

    左側はゆっくり後ろに、右側は全速で前に回るので、ロボットは **左に回転** します。左右の速さが違うので、その場で回るのではなく、少し前に進みながら左に回ります。

    300は`tankDrive()`ではなく、`run()`の中で255に直されます。
