# ピンを割り当てる

ここまでの章で、タイヤ・射出機構・PS4コントローラー・DFPlayerを別々に動かせるようになりました。この章では、これらを **1つのロボット** にまとめます。

完成したプログラムはこのドキュメントには載せません。ここまでの章のコードを組み合わせて、**自分で完成させます**。この章では、そのための手順と確かめ方を説明します。

まずは、どの部品をどのピンに繋ぐかを決めます。これまでの章のピン番号はすべて「例」でした。ここで決めたピン番号を、配線とプログラムの両方で使います。

## 必要なピンを数える

| 部品 | 数 | 1つあたりに必要なピン | 合計 |
| --- | --- | --- | --- |
| タイヤ用の`Motor` | 4 | PWM 1本(ENA・ENB) + Digital 2本(IN) | PWM 4本 + Digital 8本 |
| 射出用の`Motor` | 2(モーターは3つ) | PWM 1本 + Digital 2本 | PWM 2本 + Digital 4本 |
| DFPlayer | 1 | TX1・RX1 | 18番・19番 |
| USBホストシールド | 1 | 決まったピン | 9番・10番・50〜52番 |

`Motor`は全部で6つなので、**PWMのピンが6本**、**IN用のDigital Pinが12本** 必要です。

## 使ってはいけないピン

| ピン | 理由 |
| --- | --- |
| 0番・1番 | パソコンとの通信(書き込み・シリアルモニタ)に使う |
| 9番・10番 | USBホストシールドが使う |
| 50〜52番 | USBホストシールドがICSP端子を通して使う(SPI) |
| 53番 | SPIを使うときにマイコンが使うので空けておく |
| 18番・19番 | DFPlayer(Serial1)に使う |

## 空けておくと良いピン

| ピン | 理由 |
| --- | --- |
| 13番 | 基板のLEDに繋がっていて、状態の表示に使える |
| 20番・21番 | I2C(SDA・SCL)。あとからセンサーを足すときに使える |
| 14〜17番 | Serial2・Serial3。あとからUARTの部品を足すときに使える |

## 選べるピン

- **ENA・ENB(PWM)**: 2〜8番、11番、12番、44〜46番の中から6本
- **IN1〜IN4(Digital)**: 22〜43番、47〜49番の中から12本(44〜46番もINに使えますが、PWMのピンなのでENのために取っておきます)

!!! tip "同じモータードライバのピンは、まとめて並べると配線しやすいです"

    1つ目のモータードライバのINは22〜25番、2つ目は26〜29番…のように、**番号を続けて** 割り当てると、配線のまちがいを見つけやすくなります。

## 割り当て表を作る

次の表を写して、自分のロボットのピン番号を埋めましょう。この表は配線するときにも、プログラムを書くときにも見ます。

| モータードライバ | 出力 | 繋ぐモーター | `Motor`の名前 | EN | IN1 | IN2 |
| --- | --- | --- | --- | --- | --- | --- |
| 1つ目 | A | 左前 | `leftFront` | | | |
| 1つ目 | B | 左後ろ | `leftBack` | | | |
| 2つ目 | A | 右前 | `rightFront` | | | |
| 2つ目 | B | 右後ろ | `rightBack` | | | |
| 3つ目 | A | 射出用モーター1 | `shooterA` | | | |
| 3つ目 | B | 射出用モーター2・3 | `shooterB` | | | |

| 部品 | 端子 | マイコンのピン |
| --- | --- | --- |
| DFPlayer | RX(1kΩを挟む) | 18番(TX1) |
| DFPlayer | TX | 19番(RX1) |
| USBホストシールド | – | 9番・10番・50〜52番(重ねるだけ) |

表ができたら、次のことを確かめます。

- [ ] ENの6本が、すべてPWMのピンになっている
- [ ] 表の中に **同じ番号が2回** 出てこない
- [ ] 「使ってはいけないピン」を使っていない
- [ ] 3つのモータードライバのGNDと、マイコンのGNDが繋がっている

## 演習

ある人が作った割り当て表です。まちがっている所が **4つ** あります。どこがなぜまちがっているか答えてください。

| `Motor`の名前 | EN | IN1 | IN2 |
| --- | --- | --- | --- |
| `leftFront` | 2 | 22 | 23 |
| `leftBack` | 3 | 24 | 25 |
| `rightFront` | 26 | 27 | 28 |
| `rightBack` | 4 | 29 | 9 |
| `shooterA` | 5 | 18 | 30 |
| `shooterB` | 6 | 31 | 24 |

??? tip "ヒントを見る"

    上から1行ずつ、次の順に確かめます。

    | 確かめること | 見る所 |
    | --- | --- |
    | 1. ENはPWMのピン? | EN の列(PWMは2〜13番、44〜46番) |
    | 2. 使ってはいけないピンはない? | 0・1・9・10・18・19・50〜53番 |
    | 3. 同じ番号が2回出てこない? | 表全体 |

??? success "答えを見る"

    | 場所 | まちがい | 理由 |
    | --- | --- | --- |
    | `rightFront`のEN | 26番 | PWMのピンではないので、`analogWrite()`で速さを変えられない |
    | `rightBack`のIN2 | 9番 | USBホストシールドが使うピン |
    | `shooterA`のIN1 | 18番 | DFPlayer(Serial1のTX1)に使うピン |
    | `shooterB`のIN2 | 24番 | `leftBack`のIN1と同じ番号 |

    直し方はいくつもあります。「選べるピン」の中から、まだ使っていない番号に変えましょう。直したら、もう一度チェックリストで確かめます。
