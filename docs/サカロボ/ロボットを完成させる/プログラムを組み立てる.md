## 組み立てるときの注意

コピーするときは、次のことに気を付けます。どれも、各章のコードを **そのまま** 貼るとまちがえやすい所です。

**1. `Motor`構造体は1つだけ**

`Motor`構造体は章によって2種類あります。ピン3つだけのもの(モータードライバ・PS4コントローラー・DFPlayerの章)と、`gain`と`minSpeed`が入ったもの(タイヤ制御・射出機構の章)です。使うのは **`gain`と`minSpeed`が入った方だけ** です。2つ貼るとエラーになります。

**2. 使う前に書く**

`drive()`の中で`leftFront`を使うなら、`leftFront`の行は`drive()`より **上** に書きます。骨組みの1〜5の順番を守れば大丈夫です。

**3. `loop()`の中で`delay()`を使わない**

[音声プログラムを作る](../DFPlayer/音声プログラムを作る.md)の`loop()`には`delay()`がありますが、あれは確かめるためのものです。コントローラーで動かすプログラムに入れると、操作してから動くまで時間がかかります。

**4. DFPlayerが見つからなくても止めない**

`beginSound()`は、[音声プログラムを作る](../DFPlayer/音声プログラムを作る.md)の **`soundReady`を使う方** を持ってきます。[音を鳴らす](../DFPlayer/音を鳴らす.md)の`while (true)`で止める方を使うと、音が鳴らないだけでロボットが動かなくなります。

**5. 切れたときは、タイヤも射出機構も止める**

`loop()`の「繋がっていなければ」の所では、`tankDrive(0, 0)`と`shoot(0)`の **両方** を呼びます。

**6. 同じボタンで2つのことをするとき**

「R1を押している間は射出し、押した瞬間に1回だけ音声を流す」のように、1つのボタンで`getButtonPress()`と`getButtonClick()`を両方使うのは大丈夫です。ただし、[ボタンを使う](../PS4コントローラー/ボタンを使う.md)の脳内実行の通り、**同じボタンの`getButtonClick()`は1回しか書けません**。

## 1つずつ足して確かめる

全部を貼ってから書き込むのではなく、次の順番で **足すたびに検証と書き込みをして** 動きを確かめます。うまくいかなかったら、最後に足した所を見直せば済みます。

| 順番 | 足すもの | 確かめること |
| --- | --- | --- |
| 1 | ライブラリ、`Motor`構造体、6つの`Motor`、`setup()`の`begin()` | 検証が通る。書き込んでもモーターが勝手に回らない |
| 2 | USB・PS4の実物、`Usb.Init()`、`loop()`の`Usb.Task()`と`connected()` | コントローラーが繋がる |
| 3 | `tankDrive()`・`applyThreshold()`・`drive()` | スティックで前後・回転できる。離すと止まる |
| 4 | `shoot()`と射出のボタン | ボタンで3つの射出用モーターが回る。離すと止まる |
| 5 | `beginSound()`・`playSound()`と音声 | 決めたタイミングで音が鳴る |
| 6 | 切れたときに止める処理 | コントローラーの電源を切ると、全部のモーターが止まる |

どのボタンで何をするかは、自分たちのロボットに合わせて決めます。`readButtons()`の「押している間」「押した1回だけ」「トグル」の形から、使いたい動きに合うものを選びましょう。

## 演習

組み立ての途中で検証を押したら、次の2つのエラーが出ました。それぞれ、何が原因で、どう直せばよいでしょうか。

**エラー1**

```
error: redefinition of 'struct Motor'
```

**エラー2**

```
error: 'shooterA' was not declared in this scope
```

エラー2は、次のように書いたときに出ました。

```cpp
void shoot(int speed) {
    shooterA.run(speed);
    shooterB.run(speed);
}

//{ENA, IN1, IN2, gain, minSpeed}
Motor shooterA = {11, 30, 31, 1.00, 0};   //射出用モーター1
Motor shooterB = {12, 32, 33, 1.00, 0};   //射出用モーター2・3(並列)
```

??? tip "ヒントを見る"

    エラーの英語をそのまま訳してみます。

    | 英語 | 意味 |
    | --- | --- |
    | redefinition | 同じものを **もう一度** 作った |
    | was not declared in this scope | ここでは **まだ作られていない** |

    エラー1は「組み立てるときの注意」の1番、エラー2は2番を見直しましょう。

??? success "答えを見る"

    **エラー1: `Motor`構造体を2回書いています。**

    別々の章から`Motor`構造体をコピーして、2つ貼ってしまったときに出ます。`gain`と`minSpeed`が入った方を1つだけ残して、もう片方を消します。

    **エラー2: `shooterA`を作る前に使っています。**

    プログラムは上から順に読まれるので、`shoot()`を読んだ時点では`shooterA`がまだありません。`Motor shooterA`と`Motor shooterB`の行を、`shoot()`より **上**(骨組みの「4. 実物」)に移します。

    ```cpp
    //{ENA, IN1, IN2, gain, minSpeed}
    Motor shooterA = {11, 30, 31, 1.00, 0};   //射出用モーター1
    Motor shooterB = {12, 32, 33, 1.00, 0};   //射出用モーター2・3(並列)

    void shoot(int speed) {
        shooterA.run(speed);
        shooterB.run(speed);
    }
    ```

    エラーは一番上に出たものから直します。1つのまちがいから、下にたくさんのエラーが続けて出ることがあるからです。

## 脳内実行してみよう

組み立てたプログラムの`loop()`が次のようになっていました。射出のボタン(R1)を押して射出用モーターを回しながら、左スティックを上に倒して前進しています。この状態で **コントローラーの電池が切れました**。タイヤと射出用モーターはそれぞれどうなるでしょうか。

```cpp
void loop() {
    Usb.Task();

    if (PS4.connected()) {
        drive();
        if (PS4.getButtonPress(SHOOT_BUTTON)) {
            shoot(SHOOT_SPEED);
        } else {
            shoot(0);
        }
    } else {
        tankDrive(0, 0);
    }
}
```

??? success "答えを見る"

    **タイヤは止まりますが、射出用モーターは回り続けます。**

    | 周 | `connected()` | 実行される所 | タイヤ | 射出用モーター |
    | --- | --- | --- | --- | --- |
    | 切れる前 | `true` | `drive()`と`shoot(SHOOT_SPEED)` | 前進 | 回る |
    | 切れたあと | `false` | `else`の`tankDrive(0, 0)`だけ | **止まる** | **回ったまま** |

    `run()`は、次の命令が来るまで同じ速さで回し続けます。切れたあとは`shoot()`が一度も呼ばれないので、射出用モーターには「止まれ」の命令が届きません。

    `else`の中に`shoot(0);`を足して、「組み立てるときの注意」の5番の通りにタイヤと射出機構の **両方** を止めるようにします。
