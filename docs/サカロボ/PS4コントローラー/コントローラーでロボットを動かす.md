# コントローラーでロボットを動かす

ここまでの章をまとめて、PS4コントローラーでロボットを動かすプログラムを作ります。

- **左スティックの上下**: 前進・後退
- **右スティックの左右**: 左回転・右回転
- スティックは **しきい値以上** 傾けたときだけ動く
- ボタンは「押している間」「押した1回だけ」「トグル」の3つの形を用意しておき、あとから中身を書き足す
- コントローラーが切れたら、全部のモーターを止める

移動用のモーターは4つで、左側に2つ(前・後ろ)、右側に2つ(前・後ろ)付いているものとします。

```cpp
#include <PS4BT.h>
#include <usbhub.h>
#include <SPI.h>

#define STICK_THRESHOLD 20   //スティックのしきい値

struct Motor {
    int en;    //ENAを繋いだピン(PWM)
    int in1;   //IN1を繋いだピン
    int in2;   //IN2を繋いだピン

    //ブレーキで止める
    void stop() {
        digitalWrite(in1, LOW);
        digitalWrite(in2, LOW);
        analogWrite(en, 255);
    }

    //ピンを出力モードにして、止まった状態から始める(setupで1回呼ぶ)
    void begin() {
        pinMode(en, OUTPUT);
        pinMode(in1, OUTPUT);
        pinMode(in2, OUTPUT);
        stop();
    }

    //speedが+なら正転、-なら逆転、0なら停止(-255〜255)
    void run(int speed) {
        if (speed > 255) {
            speed = 255;
        } else if (speed < -255) {
            speed = -255;
        }

        if (speed > 0) {
            digitalWrite(in1, HIGH);
            digitalWrite(in2, LOW);
            analogWrite(en, speed);
        } else if (speed < 0) {
            digitalWrite(in1, LOW);
            digitalWrite(in2, HIGH);
            analogWrite(en, -speed);   //analogWriteには+の値を渡す
        } else {
            stop();
        }
    }
};

USB Usb;
BTD Btd(&Usb);
PS4BT PS4(&Btd);

Motor leftFront = {5, 22, 23};    //1つ目のモータードライバのA
Motor leftBack = {6, 24, 25};     //1つ目のモータードライバのB
Motor rightFront = {7, 26, 27};   //2つ目のモータードライバのA
Motor rightBack = {8, 28, 29};    //2つ目のモータードライバのB

bool isSquareOn = false;   //□のトグルの状態

//真ん中を0にした値を受け取り、しきい値より小さければ0にする
int applyThreshold(int value) {
    if (value < STICK_THRESHOLD && value > -STICK_THRESHOLD) {
        return 0;
    }
    return value;
}

//移動用のモーターを全部止める
void stopAll() {
    leftFront.stop();
    leftBack.stop();
    rightFront.stop();
    rightBack.stop();
}

//スティックでロボットを動かす
void drive() {
    int forward = applyThreshold(127 - PS4.getAnalogHat(LeftHatY)) * 2;   //前後(上が+)
    int turn = applyThreshold(PS4.getAnalogHat(RightHatX) - 127) * 2;     //回転(右が+)

    int leftSpeed = forward + turn;
    int rightSpeed = forward - turn;

    leftFront.run(leftSpeed);
    leftBack.run(leftSpeed);
    rightFront.run(rightSpeed);
    rightBack.run(rightSpeed);
}

//ボタンを読み取る
void readButtons() {
    //押している間
    if (PS4.getButtonPress(CIRCLE)) {
        //ここに○を押している間の処理を書く
    }

    //押した1回だけ
    if (PS4.getButtonClick(TRIANGLE)) {
        Serial.println("△");
        //ここに△を押したときの処理を書く
    }

    //トグル
    if (PS4.getButtonClick(SQUARE)) {
        isSquareOn = !isSquareOn;
        if (isSquareOn) {
            Serial.println("□: ON");
        } else {
            Serial.println("□: OFF");
        }
    }
    if (isSquareOn) {
        //ここに□がONの間の処理を書く
    }
}

void setup() {
    Serial.begin(9600);

    leftFront.begin();
    leftBack.begin();
    rightFront.begin();
    rightBack.begin();

    if (Usb.Init() == -1) {
        Serial.println("USBホストシールドが見つかりません");
        while (true) {
        }
    }
    Serial.println("PS4コントローラーを待っています");
}

void loop() {
    Usb.Task();

    if (PS4.connected()) {
        drive();
        readButtons();
    } else {
        stopAll();
    }
}
```

コントローラーを繋いで「△ → □ → □」の順に押すと、次のように出力されます。スティックを動かしても表示はされません。

```
PS4コントローラーを待っています
△
□: ON
□: OFF
```

!!! warning "ピン番号は実際の配線に合わせて変えてください"

    `Motor leftFront = {5, 22, 23};`などのピン番号は例です。ENA・ENBはPWMのピン(2〜13番、44〜46番)で、USBホストシールドが使う9番・10番と50〜52番は避けています。

## 前後と回転を混ぜる

左スティックの前後`forward`と右スティックの回転`turn`を、左右のモーターの速さに分けています。

```cpp
int leftSpeed = forward + turn;
int rightSpeed = forward - turn;
```

| 操作 | `forward` | `turn` | 左の速さ | 右の速さ | ロボットの動き |
| --- | --- | --- | --- | --- | --- |
| 左スティックを上 | + | 0 | + | + | 前進 |
| 左スティックを下 | - | 0 | - | - | 後退 |
| 右スティックを右 | 0 | + | + | - | その場で右回転 |
| 右スティックを左 | 0 | - | - | + | その場で左回転 |
| 左を上、右を右 | + | + | 大きい+ | 小さい | 右に曲がりながら前進 |
| 何も触らない | 0 | 0 | 0 | 0 | 止まる |

左側を前に、右側を後ろに回すと、ロボットはその場で右に回ります。両方のスティックを同時に倒すと、前後と回転が足し合わさって曲がりながら進みます。

`* 2`しているのは、スティックの値(-128〜127)をモーターの速さ(-255〜255)に近づけるためです。足し算で255を超えても、`run()`の中で255に直されるので大丈夫です。

## コントローラーが切れたら止める

`loop()`では、繋がっている間だけ`drive()`と`readButtons()`を呼び、**繋がっていないときは`stopAll()`で止めます**。

これがないと、コントローラーの電池が切れたり、離れすぎて通信が切れたりしたときに、モーターが **最後に動かした速さのまま回り続けて** しまいます。操作できないロボットが走り続けるのはとても危険なので、この`else`は消さないようにしましょう。

## ボタンに処理を書き足す

`readButtons()`には、ボタンの章で学んだ3つの形を用意してあります。ロボットに機能を足すときは、`//ここに〜の処理を書く`の所に書き足していきます。

| 形 | 書く場所 | 例えばこんなときに |
| --- | --- | --- |
| 押している間 | `getButtonPress()`の`if`の中 | 押している間だけモーターを回す |
| 押した1回だけ | `getButtonClick()`の`if`の中 | 押したときに1回だけ音を鳴らす |
| トグル | `if (isSquareOn)`の中 | 1回押したらON、もう1回でOFFにしたい動き |

使うボタンを変えるときは、`CIRCLE`などの名前をボタンの章の表から選んで書き換えます。トグルを増やすときは、`isSquareOn`とは **別の`bool`の変数** を`loop()`の外に作ります。

!!! warning "`readButtons()`や`drive()`の中で`delay()`を使わないでください"

    `delay()`で待っている間は`Usb.Task()`が呼ばれないので、スティックを戻してもロボットが止まりません。

## 演習

練習として、□のトグルがONの間は **速さを半分** にして、ゆっくり動かせるようにしてください。

??? tip "ヒントを見る"

    `drive()`の中で、`forward`と`turn`を計算したあと、モーターに渡す前に半分にします。

    | やること | 書き方 |
    | --- | --- |
    | 1. `turn`を計算した行の下で、トグルの状態を調べる | `if (isSquareOn)` |
    | 2. ONなら前後を半分にする | `forward = forward / 2;` |
    | 3. ONなら回転も半分にする | `turn = turn / 2;` |

    `readButtons()`の`if (isSquareOn)`の中に書いても、`forward`と`turn`は`drive()`の中の変数なので使えません。

??? success "答えを見る"

    変わるのは`drive()`だけなので、そこだけ示します。

    ```cpp
    //スティックでロボットを動かす
    void drive() {
        int forward = applyThreshold(127 - PS4.getAnalogHat(LeftHatY)) * 2;   //前後(上が+)
        int turn = applyThreshold(PS4.getAnalogHat(RightHatX) - 127) * 2;     //回転(右が+)

        if (isSquareOn) {
            forward = forward / 2;
            turn = turn / 2;
        }

        int leftSpeed = forward + turn;
        int rightSpeed = forward - turn;

        leftFront.run(leftSpeed);
        leftBack.run(leftSpeed);
        rightFront.run(rightSpeed);
        rightBack.run(rightSpeed);
    }
    ```

    左スティックを上いっぱいにしたとき、OFFなら`forward`は254、ONなら127になります。

## 脳内実行してみよう

上のプログラム(演習の前のもの)で、`getAnalogHat(LeftHatY)`が **27**、`getAnalogHat(RightHatX)`が **177** のとき、`leftFront`と`rightFront`の`run()`にはそれぞれいくつが渡されるでしょうか。また、実際にENAに出力される値はいくつで、ロボットはどう動くでしょうか。

??? success "答えを見る"

    `leftFront.run()`には **300**、`rightFront.run()`には **100** が渡されます。ENAに出力されるのは左が **255**、右が **100** で、ロボットは **右に曲がりながら前進** します。

    | 計算 | 値 |
    | --- | --- |
    | `127 - 27` | 100 |
    | `applyThreshold(100)` | 100(20以上なのでそのまま) |
    | `forward = 100 * 2` | 200 |
    | `177 - 127` | 50 |
    | `applyThreshold(50)` | 50(20以上なのでそのまま) |
    | `turn = 50 * 2` | 100 |
    | `leftSpeed = 200 + 100` | 300 |
    | `rightSpeed = 200 - 100` | 100 |

    `leftFront.run(300)`は、`run()`の最初で255に直されてから正転します。`rightFront.run(100)`はそのまま速さ100で正転します。左の方が速いので、右に曲がりながら前に進みます。
