# ボタンを使う

コントローラーと繋がったので、ボタンを読み取ってみましょう。ボタンには、使い方によって3つの読み取り方があります。

| 読み取り方 | いつ`true`になるか | 向いている使い方 |
| --- | --- | --- |
| **押している間** | ボタンを押している間ずっと | 押している間だけ動かす |
| **押した1回だけ** | ボタンを押した瞬間に1回だけ | 押すたびに1回だけ何かをする |
| **トグル** | 押すたびにONとOFFが切り替わる | 1回押したらON、もう1回押したらOFF |

どのボタンに何をさせるかはロボットによって変わるので、ここではLEDとシリアルモニタで3つの読み取り方を確かめます。

```cpp
#include <PS4BT.h>
#include <usbhub.h>
#include <SPI.h>

#define LED_PIN 12
#define STATUS_LED_PIN 13

USB Usb;
BTD Btd(&Usb);
PS4BT PS4(&Btd);

int clickCount = 0;          //△を押した回数
bool isToggleOn = false;     //□のトグルの状態

void setup() {
    Serial.begin(9600);
    pinMode(LED_PIN, OUTPUT);
    pinMode(STATUS_LED_PIN, OUTPUT);

    if (Usb.Init() == -1) {
        Serial.println("USBホストシールドが見つかりません");
        while (true) {
        }
    }
    Serial.println("PS4コントローラーを待っています");
}

void loop() {
    Usb.Task();

    if (PS4.connected()) {
        //押している間: ○を押している間だけ12番のLEDが点く
        if (PS4.getButtonPress(CIRCLE)) {
            digitalWrite(LED_PIN, HIGH);
        } else {
            digitalWrite(LED_PIN, LOW);
        }

        //押した1回だけ: △を押すたびに回数を1増やして表示する
        if (PS4.getButtonClick(TRIANGLE)) {
            clickCount++;
            Serial.print("△を押した回数: ");
            Serial.println(clickCount);
        }

        //トグル: □を押すたびに13番のLEDのON/OFFが切り替わる
        if (PS4.getButtonClick(SQUARE)) {
            isToggleOn = !isToggleOn;
            if (isToggleOn) {
                digitalWrite(STATUS_LED_PIN, HIGH);
                Serial.println("□: ON");
            } else {
                digitalWrite(STATUS_LED_PIN, LOW);
                Serial.println("□: OFF");
            }
        }
    }
}
```

コントローラーを繋いで「△ → △ → □ → △ → □」の順に押すと、次のように出力されます。

```
PS4コントローラーを待っています
△を押した回数: 1
△を押した回数: 2
□: ON
△を押した回数: 3
□: OFF
```

## 押している間: getButtonPress()

`PS4.getButtonPress(ボタン名)`は、そのボタンを **押している間ずっと`true`** になります。`loop()`は1秒に何百回も回るので、押している間は毎回`true`が返ってきます。

## 押した1回だけ: getButtonClick()

`PS4.getButtonClick(ボタン名)`は、ボタンを押した瞬間に **1回だけ`true`** になり、そのあとは押したままでも`false`です。もう一度`true`にするには、一度離してから押し直します。

もし△の読み取りを`getButtonPress()`にすると、押している間`loop()`が回るたびに`clickCount++`が実行されて、1回押しただけで回数が何百も増えてしまいます。

## トグル: getButtonClick()と!

トグル専用の関数はありません。`getButtonClick()`と、演算子の章の`!`(ではない)を組み合わせて作ります。

```cpp
isToggleOn = !isToggleOn;
```

`!isToggleOn`は「`isToggleOn`ではない方」なので、`false`なら`true`に、`true`なら`false`に入れ替わります。押すたびにこの1行が1回だけ実行されるので、ONとOFFが交互に切り替わります。

!!! warning "トグルには必ず`getButtonClick()`を使います"

    `getButtonPress()`でトグルを作ると、押している間`loop()`が回るたびにONとOFFが何度も入れ替わり、指を離したときにどちらになっているかわからなくなります。

`isToggleOn`や`clickCount`は`loop()`の **外** に書いています。`loop()`の中に書くと、`loop()`が1周するたびに`false`や0に戻ってしまい、前の状態を覚えておけません。

## ボタンの名前

| ボタン | 書き方 |
| --- | --- |
| ○ △ □ × | `CIRCLE` `TRIANGLE` `SQUARE` `CROSS` |
| 十字キー ↑ → ↓ ← | `UP` `RIGHT` `DOWN` `LEFT` |
| L1 R1 | `L1` `R1` |
| L2 R2 | `L2` `R2` |
| スティックの押し込み(左・右) | `L3` `R3` |
| SHARE OPTIONS | `SHARE` `OPTIONS` |
| PSボタン タッチパッドの押し込み | `PS` `TOUCHPAD` |

どのボタンも`getButtonPress()`と`getButtonClick()`の両方で使えます。

## 演習

上のプログラムに、次の2つを追加してください。

- ×を押すたびに`clickCount`を0に戻して「リセット」と表示する
- R1を押すたびにトグルを切り替えて、ONの間はシリアルモニタに「R1: ON」、OFFになったら「R1: OFF」と表示する(□とは別のトグルにする)

??? tip "ヒントを見る"

    | やること | 読み取り方 | 書き方 |
    | --- | --- | --- |
    | 1. R1用のトグルの変数を作る | – | `loop()`の外に`bool isR1On = false;` |
    | 2. ×で回数を0に戻す | 押した1回だけ | `if (PS4.getButtonClick(CROSS))`の中で`clickCount = 0;` |
    | 3. R1でトグルを切り替える | トグル | `if (PS4.getButtonClick(R1))`の中で`isR1On = !isR1On;` |
    | 4. R1の状態を表示する | – | 3の中で`if (isR1On)`と`else`で表示を分ける |

    □のトグルと同じ変数`isToggleOn`を使うと、□とR1のどちらを押しても同じものが切り替わってしまいます。

??? success "答えを見る"

    ```cpp
    #include <PS4BT.h>
    #include <usbhub.h>
    #include <SPI.h>

    #define LED_PIN 12
    #define STATUS_LED_PIN 13

    USB Usb;
    BTD Btd(&Usb);
    PS4BT PS4(&Btd);

    int clickCount = 0;          //△を押した回数
    bool isToggleOn = false;     //□のトグルの状態
    bool isR1On = false;         //R1のトグルの状態

    void setup() {
        Serial.begin(9600);
        pinMode(LED_PIN, OUTPUT);
        pinMode(STATUS_LED_PIN, OUTPUT);

        if (Usb.Init() == -1) {
            Serial.println("USBホストシールドが見つかりません");
            while (true) {
            }
        }
        Serial.println("PS4コントローラーを待っています");
    }

    void loop() {
        Usb.Task();

        if (PS4.connected()) {
            //押している間: ○を押している間だけ12番のLEDが点く
            if (PS4.getButtonPress(CIRCLE)) {
                digitalWrite(LED_PIN, HIGH);
            } else {
                digitalWrite(LED_PIN, LOW);
            }

            //押した1回だけ: △を押すたびに回数を1増やして表示する
            if (PS4.getButtonClick(TRIANGLE)) {
                clickCount++;
                Serial.print("△を押した回数: ");
                Serial.println(clickCount);
            }

            //押した1回だけ: ×を押すたびに回数を0に戻す
            if (PS4.getButtonClick(CROSS)) {
                clickCount = 0;
                Serial.println("リセット");
            }

            //トグル: □を押すたびに13番のLEDのON/OFFが切り替わる
            if (PS4.getButtonClick(SQUARE)) {
                isToggleOn = !isToggleOn;
                if (isToggleOn) {
                    digitalWrite(STATUS_LED_PIN, HIGH);
                    Serial.println("□: ON");
                } else {
                    digitalWrite(STATUS_LED_PIN, LOW);
                    Serial.println("□: OFF");
                }
            }

            //トグル: R1を押すたびにON/OFFが切り替わる
            if (PS4.getButtonClick(R1)) {
                isR1On = !isR1On;
                if (isR1On) {
                    Serial.println("R1: ON");
                } else {
                    Serial.println("R1: OFF");
                }
            }
        }
    }
    ```

    「△ → △ → × → R1 → △ → R1」の順に押すと、出力は次のようになります。

    ```
    PS4コントローラーを待っています
    △を押した回数: 1
    △を押した回数: 2
    リセット
    R1: ON
    △を押した回数: 1
    R1: OFF
    ```

## 脳内実行してみよう

`loop()`の中に次のコードを書きました。コントローラーの○ボタンを **1回だけ** 押したとき、シリアルモニタには何が表示されるでしょうか。

```cpp
if (PS4.getButtonClick(CIRCLE)) {
    Serial.println("A");
}
if (PS4.getButtonClick(CIRCLE)) {
    Serial.println("B");
}
```

??? success "答えを見る"

    ```
    A
    ```

    **Aだけ** が表示され、Bは表示されません。

    | 実行する行 | 結果 | 何が起きるか |
    | --- | --- | --- |
    | 1つ目の`getButtonClick(CIRCLE)` | `true` | 「A」と表示。「押された」という記録はここで使われて消える |
    | 2つ目の`getButtonClick(CIRCLE)` | `false` | 記録がもう消えているので何もしない |
    | 次の周の`loop()`から | `false` | 押し直すまでずっと`false` |

    `getButtonClick()`は、**呼んだ時点で「押された」という記録を使い切ります**。同じボタンの`getButtonClick()`を2回書くと、2つ目は必ず`false`になります。1回押したときに2つのことをしたいときは、1つの`if`の中にまとめて書きましょう。
