# スティックを使う

ボタンはONかOFFの2つだけでしたが、スティックは **どれだけ傾けたか** を数で読み取れます。この数をモーターの速さに使えば、少し傾けたらゆっくり、大きく傾けたら速く動かせます。

ここでは、左スティックの上下と右スティックの左右を読み取ってみます。

```cpp
#include <PS4BT.h>
#include <usbhub.h>
#ifdef dobogusinclude
#include <spi4teensy3.h>
#endif
#include <SPI.h>

USB Usb;
BTD Btd(&Usb);
PS4BT PS4(&Btd);

void setup() {
    Serial.begin(9600);

    #if !defined(__MIPSEL__)
        while (!Serial);
    #endif
        if (Usb.Init() == -1) {
            Serial.print("USBホストシールドが見つかりません");
            while (1);
        }
        Serial.println("PS4コントローラーを待っています");
}

void loop() {
    Usb.Task();

    if (PS4.connected()) {
        Serial.print("左スティック上下: ");
        Serial.print(PS4.getAnalogHat(LeftHatY));
        Serial.print("  右スティック左右: ");
        Serial.println(PS4.getAnalogHat(RightHatX));
        delay(100);
    }
}
```

スティックを「触らない → 左スティックを上いっぱい → 右スティックを右いっぱい」と動かすと、次のように出力されます(値は少しずれることがあります)。

```
PS4コントローラーを待っています
左スティック上下: 127  右スティック左右: 127
左スティック上下: 0  右スティック左右: 127
左スティック上下: 127  右スティック左右: 255
.
.
.
```

`delay(100)`は表示が速すぎて読めなくなるのを防ぐためだけに入れています。

## スティックの値

`PS4.getAnalogHat(スティック名)`は、傾きを **0〜255** で返します。

| 書き方 | 読み取る向き | 0のとき | 真ん中(約127) | 255のとき |
| --- | --- | --- | --- | --- |
| `LeftHatX` | 左スティックの左右 | 左いっぱい | 触らない | 右いっぱい |
| `LeftHatY` | 左スティックの上下 | **上** いっぱい | 触らない | **下** いっぱい |
| `RightHatX` | 右スティックの左右 | 左いっぱい | 触らない | 右いっぱい |
| `RightHatY` | 右スティックの上下 | **上** いっぱい | 触らない | **下** いっぱい |

上下(Y)は **上に倒すほど小さく** なります。「上が大きい」と思っていると逆になるので気を付けましょう。

## 真ん中を0にする

このままだと「触らない」が127なので、モーターの速さに使いにくいです。`Motor`の`run()`は「+で正転、-で逆転、0で停止」だったので、スティックも **真ん中を0** にそろえます。

```cpp
int value = PS4.getAnalogHat(RightHatX) - 127;
```

| スティック | `getAnalogHat()` | `- 127`した値 |
| --- | --- | --- |
| 左いっぱい | 0 | -127 |
| 触らない | 127 | 0 |
| 右いっぱい | 255 | 128 |

上下(Y)は上が小さいので、引き算を逆にして **上が+** になるようにします。

```cpp
int value = 127 - PS4.getAnalogHat(LeftHatY);
```

| スティック | `getAnalogHat()` | `127 -`した値 |
| --- | --- | --- |
| 上いっぱい | 0 | 127 |
| 触らない | 127 | 0 |
| 下いっぱい | 255 | -128 |

## しきい値

スティックは指を離しても、ぴったり127に戻るとは限りません。125や130のように少しずれて止まることがあります。このずれをそのままモーターに渡すと、**触っていないのにロボットがゆっくり動いてしまいます**。

そこで「**しきい値** より小さい傾きは0にする」と決めます。しきい値以上傾けたときだけ、動かす値として使います。

```cpp
#define STICK_THRESHOLD 20   //しきい値

//真ん中を0にした値を受け取り、しきい値より小さければ0にする
int applyThreshold(int value) {
    if (value < STICK_THRESHOLD && value > -STICK_THRESHOLD) {
        return 0;
    }
    return value;
}
```

| `value` | 条件 | 返す値 |
| --- | --- | --- |
| 5 | -20より大きく20より小さい | 0 |
| -12 | -20より大きく20より小さい | 0 |
| 20 | 20より小さくない | 20 |
| -90 | -20より大きくない | -90 |

しきい値を大きくすると触っていないときに動きにくくなりますが、少しだけ傾けても反応しなくなります。コントローラーによってずれ方が違うので、実際に値を表示して決めましょう。

## 演習

`applyThreshold()`を使って、左スティックの上下を「上が+、真ん中が0」の値にしてシリアルモニタに表示するプログラムを書いてください。さらに、その値が+なら「前」、-なら「後ろ」、0なら「止まる」と表示しましょう。しきい値は20にします。

??? tip "ヒントを見る"

    | やること | 書き方 |
    | --- | --- |
    | 1. しきい値に名前を付けて、`applyThreshold()`を書く | 上の「しきい値」のコードをそのまま使う |
    | 2. 上が+になるように直す | `127 - PS4.getAnalogHat(LeftHatY)` |
    | 3. しきい値を通す | `int forward = applyThreshold(2の値);` |
    | 4. 値を表示する | `Serial.print(forward);` |
    | 5. 向きを表示する | `if (forward > 0)`、`else if (forward < 0)`、`else`で分ける |

    表示が速すぎないように、最後に`delay(100);`を入れましょう。

??? success "答えを見る"

    ```cpp
    #include <PS4BT.h>
    #include <usbhub.h>
    #ifdef dobogusinclude
    #include <spi4teensy3.h>
    #endif
    #include <SPI.h>

    #define STICK_THRESHOLD 20   //しきい値

    USB Usb;
    BTD Btd(&Usb);
    PS4BT PS4(&Btd);

    //真ん中を0にした値を受け取り、しきい値より小さければ0にする
    int applyThreshold(int value) {
        if (value < STICK_THRESHOLD && value > -STICK_THRESHOLD) {
            return 0;
        }
        return value;
    }

    void setup() {
        Serial.begin(9600);

        #if !defined(__MIPSEL__)
            while (!Serial);
        #endif
            if (Usb.Init() == -1) {
                Serial.print("USBホストシールドが見つかりません");
                while (1);
            }
            Serial.println("PS4コントローラーを待っています");
    }

    void loop() {
        Usb.Task();

        if (PS4.connected()) {
            int forward = applyThreshold(127 - PS4.getAnalogHat(LeftHatY));

            Serial.print(forward);
            if (forward > 0) {
                Serial.println(" 前");
            } else if (forward < 0) {
                Serial.println(" 後ろ");
            } else {
                Serial.println(" 止まる");
            }
            delay(100);
        }
    }
    ```

    左スティックを「触らない → 上いっぱい → 下いっぱい」と動かすと、出力は次のようになります。

    ```
    PS4コントローラーを待っています
    0 止まる
    127 前
    -128 後ろ
    .
    .
    .
    ```

## 脳内実行してみよう

上の演習の答えのプログラムで、左スティックの`getAnalogHat(LeftHatY)`が次の値だったとき、シリアルモニタにはそれぞれ何が表示されるでしょうか。

1. 118
2. 107
3. 150

??? success "答えを見る"

    ```
    0 止まる
    20 前
    -23 後ろ
    ```

    | `getAnalogHat()` | `127 -`した値 | `applyThreshold()`の条件 | `forward` | 表示 |
    | --- | --- | --- | --- | --- |
    | 118 | 9 | -20より大きく20より小さい | 0 | `0 止まる` |
    | 107 | 20 | 20より小さくない | 20 | `20 前` |
    | 150 | -23 | -20より大きくない | -23 | `-23 後ろ` |

    2番目の20は、しきい値とぴったり同じです。`value < STICK_THRESHOLD`は「20より小さい」なので、20は当てはまらず、そのまま20が返ります。**しきい値「以上」傾けたら動く** ということです。

    3番目は`getAnalogHat()`が127より大きい(下に倒した)ので、`127 - 150`でマイナスになり「後ろ」です。
