# 繰り返し

PWMの章で、明るさを0から254まで1ずつ変えるのに`for`文を使いました。ここでは`for`をあらためて整理して、もう一つの繰り返しである`while`と、途中で抜ける`break`を学びます。

```cpp
#define LED_PIN 12
#define STATUS_LED_PIN 13

void setup() {
    Serial.begin(9600);
    pinMode(LED_PIN, OUTPUT);
    pinMode(STATUS_LED_PIN, OUTPUT);

    //起動の合図にLEDを3回点滅させる
    for (int i = 0; i < 3; i++) {
        digitalWrite(STATUS_LED_PIN, HIGH);
        delay(200);
        digitalWrite(STATUS_LED_PIN, LOW);
        delay(200);
        Serial.print("点滅 ");
        Serial.println(i + 1);
    }

    //目標の明るさまでだんだん明るくする
    int brightness = 0;
    while (brightness < 200) {
        brightness += 50;
        analogWrite(LED_PIN, brightness);
        Serial.print("brightness = ");
        Serial.println(brightness);
        delay(100);
    }
    Serial.println("目標の明るさになりました");
}

void loop() {
}
```

このコードは次のように出力されます。

```
点滅 1
点滅 2
点滅 3
brightness = 50
brightness = 100
brightness = 150
brightness = 200
目標の明るさになりました
```

## for

`for (初期化; 条件; 更新)`と書きます。**回数が決まっている**繰り返しに向いています。

上の例では`i`が0から始まり、`i < 3`の間だけ`{ }`の中を実行し、1回終わるごとに`i++`で1増えます。つまり`i`が0、1、2の3回だけ点滅します。

## while

`while (条件)`と書くと、**条件が正しい間ずっと**繰り返します。「目標の明るさになるまで明るくし続ける」のように、何回繰り返すか決まっていない処理に向いています。

上の例では`brightness`が200未満の間だけ繰り返すので、50→100→150→200と明るくなって止まります。

!!! warning "条件がずっと正しいと止まらなくなります"

    `while (brightness < 200)`の中で`brightness`を増やし忘れると、条件が永遠に正しいままになり、プログラムはそこから先へ進めなくなります(無限ループ)。マイコンは電源を切るまで固まったままになるので、**繰り返しの中で条件に関わる変数が必ず変化するか**を確認しましょう。

## break

繰り返しの途中で抜け出したいときは`break`を使います。「異常を見つけたらすぐ止める」といった処理に使えます。

```cpp
    for (int i = 0; i < 100; i++) {
        if (i == 5) {
            Serial.println("5回で中断します");
            break;              //ここでfor文を抜ける
        }
        Serial.print("回数 ");
        Serial.println(i);
    }
```

このコードは次のように出力されます。

```
回数 0
回数 1
回数 2
回数 3
回数 4
5回で中断します
```

`i`が5になった時点で`break`が実行され、100回まで繰り返さずにfor文を抜けます。条件分岐の章で出てきた`switch`の`break`と同じキーワードです。

## 演習

`while`を使って、`brightness`を255から0まで5ずつ下げながら`analogWrite()`でLEDを暗くしていくプログラムを書いてください。明るさが変わるたびにシリアルモニタにも値を表示しましょう。

??? tip "ヒントを見る"

    `while`を書くときは、次の3つをセットで考えると迷いません。1つでも欠けると動きません。

    | 決めること | 今回の場合 | 書く場所 |
    | --- | --- | --- |
    | 1. **どこから始める?** | 255から | `while`より前(`int brightness = 255;`) |
    | 2. **いつまで続ける?** | 0より大きい間 | `while (brightness > 0)` |
    | 3. **どう変化させる?** | 5ずつ減らす | `{ }`の中(`brightness -= 5;`) |

    3を書き忘れると`brightness`が255のまま変わらず、条件がずっと正しいので永遠に止まりません(無限ループ)。

    `{ }`の中身は、上のサンプルの「だんだん明るくする」部分をコピーして、`+=`を`-=`に、開始の値を0から255に変えるだけで作れます。

??? success "答えを見る"

    ```cpp
    #define LED_PIN 12

    void setup() {
        Serial.begin(9600);
        pinMode(LED_PIN, OUTPUT);

        int brightness = 255;
        while (brightness > 0) {
            brightness -= 5;             //5だけ暗くする
            analogWrite(LED_PIN, brightness);
            Serial.print("brightness = ");
            Serial.println(brightness);
            delay(100);
        }
        Serial.println("消灯しました");
    }

    void loop() {
    }
    ```

    出力は次のようになります。

    ```
    brightness = 250
    brightness = 245
    brightness = 240
    .
    .
    .
    brightness = 5
    brightness = 0
    消灯しました
    ```

    `brightness -= 5;`を書き忘れると`brightness`がずっと255のままになり、`while`の条件が永遠に正しくなって止まらなくなります(無限ループ)。

## 脳内実行してみよう

次のコードを実行すると、シリアルモニタには何が表示されるでしょうか。

```cpp
void setup() {
    Serial.begin(9600);

    int count = 0;
    for (int i = 0; i < 4; i++) {
        count += i;
        Serial.println(count);
    }
}

void loop() {
}
```

??? success "答えを見る"

    ```
    0
    1
    3
    6
    ```

    | 何周目 | 周のはじめの`i` | `count += i;`のあと |
    | --- | --- | --- |
    | 1周目 | 0 | 0 + 0 = 0 |
    | 2周目 | 1 | 0 + 1 = 1 |
    | 3周目 | 2 | 1 + 2 = 3 |
    | 4周目 | 3 | 3 + 3 = 6 |
    | (5周目) | 4 | `i < 4`が成り立たないので終了 |

    `for`は「最初に1回だけ`int i = 0`」→「`i < 4`を調べる」→「`{ }`を実行」→「`i++`で1増やす」→「調べるところに戻る」の順で動きます。`i`が4になると`{ }`は実行されないので、4回で終わりです。

    `count`は`for`の外で作った変数なので、周をまたいで値が残ります。
