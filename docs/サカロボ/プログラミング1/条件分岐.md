# 条件分岐

マイコンは「バッテリーが減っていたらLEDで知らせる」「モードによって光らせ方を切り替える」のように、状況に応じて動きを変える必要があります。そのための仕組みが条件分岐です。

```cpp
#define LED_PIN 12
#define STATUS_LED_PIN 13

int brightness = 200;   //LEDの明るさ

void setup() {
    Serial.begin(9600);
    pinMode(LED_PIN, OUTPUT);
    pinMode(STATUS_LED_PIN, OUTPUT);

    if (brightness > 255) {          //255を超えていたら255に直す
        brightness = 255;
        Serial.println("明るすぎるので255にしました");
    }

    if (brightness == 0) {
        digitalWrite(STATUS_LED_PIN, LOW);    //消えているので合図のLEDも消す
        Serial.println("消灯中");
    } else if (brightness < 128) {
        digitalWrite(STATUS_LED_PIN, HIGH);
        Serial.println("暗めに点灯中");
    } else {
        digitalWrite(STATUS_LED_PIN, HIGH);
        Serial.println("明るく点灯中");
    }

    analogWrite(LED_PIN, brightness);
}

void loop() {
}
```

このコードは次のように出力されます。

```
明るく点灯中
```

## if

`if (条件) { 処理 }`と書くと、条件が正しい(`true`)ときだけ`{ }`の中が実行されます。条件には前の章の比較演算子やブール演算子を使います。

上の例の最初の`if`は、`brightness`が255を超えていたら255に直す安全装置です。`analogWrite()`は0〜255しか受け取れないので、こうしたチェックは実際のプログラムでもよく書きます。

## if / else if / else

- `if`: 最初の条件
- `else if`: 前の条件が違ったときの、次の条件
- `else`: どの条件にも当てはまらなかったとき

上から順に調べていき、**最初に当てはまったものだけ**が実行されます。`brightness`が200のときは`brightness == 0`も`brightness < 128`も違うので、`else`の「明るく点灯中」が実行されます。

## switch case

1つの変数を複数の値とくらべるときは、`switch`を使うと見やすく書けます。動作モードの切り替えが典型例です。

```cpp
#define LED_PIN 12

int mode = 2;   //1=明るく点灯, 2=暗く点灯, 3=消灯

void setup() {
    Serial.begin(9600);
    pinMode(LED_PIN, OUTPUT);

    switch (mode) {
        case 1:
            Serial.println("明るく点灯");
            analogWrite(LED_PIN, 255);
            break;
        case 2:
            Serial.println("暗く点灯");
            analogWrite(LED_PIN, 60);
            break;
        case 3:
            Serial.println("消灯");
            analogWrite(LED_PIN, 0);
            break;
        default:
            Serial.println("不明なモードです");
            break;
    }
}

void loop() {
}
```

このコードは次のように出力されます。

```
暗く点灯
```

`case 値:`が「その値だったときの処理」、`default:`が「どれにも当てはまらなかったとき」です。

!!! warning "`break`を忘れると下のcaseまで実行されます"

    `break`を書かないと、caseの下にあるcaseの処理まで続けて実行されてしまうので、各caseの最後には必ず`break`を書きましょう。

## 演習

上の`switch`のプログラムに`case 4:`として「中くらいの明るさ」を追加し、`analogWrite()`で150にしてください。`mode`を4に変えて、シリアルモニタに「中くらいの明るさ」と出ることを確かめましょう。

??? tip "ヒントを見る"

    新しく1から書くのではなく、既にある`case 3:`のかたまりを見本にします。`case`は3行1組で、どれも同じ形をしています。

    ```
    case 番号:
        Serial.println("表示したい文字");
        analogWrite(LED_PIN, 明るさ);
        break;
    ```

    | やること | 書き方 |
    | --- | --- |
    | 1. `case 3:`のかたまり(4行)をコピーして下に貼る | `default:`より上に置く |
    | 2. 番号を4に変える | `case 4:` |
    | 3. 表示する文字を変える | `Serial.println("中くらいの明るさ");` |
    | 4. 明るさを150に変える | `analogWrite(LED_PIN, 150);` |
    | 5. `break;`が付いているか確認する | 消さずに残す |
    | 6. 動かすモードを4にする | `int mode = 4;` |

    最後の6を忘れると`mode`が2のままなので、「暗く点灯」が表示されて「あれ?」となります。

??? success "答えを見る"

    ```cpp
    #define LED_PIN 12

    int mode = 4;   //1=明るく点灯, 2=暗く点灯, 3=消灯, 4=中くらいの明るさ

    void setup() {
        Serial.begin(9600);
        pinMode(LED_PIN, OUTPUT);

        switch (mode) {
            case 1:
                Serial.println("明るく点灯");
                analogWrite(LED_PIN, 255);
                break;
            case 2:
                Serial.println("暗く点灯");
                analogWrite(LED_PIN, 60);
                break;
            case 3:
                Serial.println("消灯");
                analogWrite(LED_PIN, 0);
                break;
            case 4:
                Serial.println("中くらいの明るさ");
                analogWrite(LED_PIN, 150);
                break;
            default:
                Serial.println("不明なモードです");
                break;
        }
    }

    void loop() {
    }
    ```

    出力は次のようになります。

    ```
    中くらいの明るさ
    ```

    `case 4:`の最後にも`break`を忘れずに書きましょう。書き忘れると、続けて`default`の「不明なモードです」まで実行されてしまいます。

## 脳内実行してみよう

次のコードでは`case 1:`の`break`がわざと書かれていません。シリアルモニタには何が表示されるでしょうか。

```cpp
#define LED_PIN 12

int mode = 1;

void setup() {
    Serial.begin(9600);
    pinMode(LED_PIN, OUTPUT);

    switch (mode) {
        case 1:
            Serial.println("明るく点灯");
        case 2:
            Serial.println("暗く点灯");
            break;
        case 3:
            Serial.println("消灯");
            break;
    }
}

void loop() {
}
```

??? success "答えを見る"

    ```
    明るく点灯
    暗く点灯
    ```

    | 順番 | 実行する行 | 何が起きるか |
    | --- | --- | --- |
    | 1 | `switch (mode)` | `mode`は1なので`case 1:`へジャンプ |
    | 2 | `Serial.println("明るく点灯");` | 「明るく点灯」を表示 |
    | 3 | `case 2:` | **`break`がないので、そのまま下へ進む** |
    | 4 | `Serial.println("暗く点灯");` | 「暗く点灯」を表示 |
    | 5 | `break;` | ここで`switch`を抜ける |

    `case`は **入口** を決めるだけで、**出口を決めるのは`break`** です。`case 1:`の最後に`break;`を足すと「明るく点灯」の1行だけになります。
