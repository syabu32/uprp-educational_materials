# シリアル通信

それではプログラムを作ってみましょう。以下のプログラムをコピペして検証ボタンで正常に実行されるか見てみましょう。

実機が手元にないのでどう動くかわからないと思いますが、なるべく実行結果を示すので頑張って追ってください。

```cpp
void setup() {
    //プログラムが一度だけ実行されます。
    //初期化コードをここに書きます。
    Serial.begin(9600); //通信速度の初期化
    Serial.println("初期化しました。");
}

void loop() {
    //プログラムが繰り返し実行されます。
    //初期化後のプログラムをここで動かします。
    Serial.println("プログラム1が実行されました。");
    Serial.println(78);
    Serial.print('U');
    Serial.println("P-RP");
}
```

このコードは次のように出力されます。実機があれば、右上の **ツール** → **シリアルモニタ** を選択し、通信速度を`Serial.begin()`の引数(今回は9600)と同じにすることで見ることができます。

```
初期化しました。
プログラム1が実行されました。
78
UP-RP
プログラム1が実行されました。
78
UP-RP
プログラム1が実行されました。
78
UP-RP
プログラム1が実行されました。
78
UP-RP
.
.
.
```

シリアルモニタでマイコンからの文字を受け取るときは`Serial.begin();`で通信を初期化してから、`Serial.println();`で文字を出力することができます。
見ての通りC言語やC++と文法が同じなので授業の内容を忘れていなければ直ぐに書けると思います。
