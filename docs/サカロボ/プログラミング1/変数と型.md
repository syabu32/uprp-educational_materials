# 変数と型

ここまでは`analogWrite(12, 200)`のように数字を直接書いてきました。ですが実際のプログラムでは、ピン番号や明るさに名前を付けて管理します。名前を付けておくと、配線を変えたときに1か所だけ直せば済むようになります。

```cpp
#define LED_PIN 12          //明るさを変えるLEDのピン番号
#define STATUS_LED_PIN 13   //状態を知らせるLEDのピン番号

int brightness = 200;        //LEDの明るさ(0〜255)
unsigned int count = 0;      //光らせた回数(マイナスにならない)
float voltage = 4.85;        //測定したバッテリーの電圧

void setup() {
    Serial.begin(9600);
    pinMode(LED_PIN, OUTPUT);
    pinMode(STATUS_LED_PIN, OUTPUT);

    digitalWrite(STATUS_LED_PIN, HIGH);   //動作中の合図にLEDを点ける
    analogWrite(LED_PIN, brightness);     //変数の値でLEDを光らせる
    count = count + 1;                    //光らせた回数を1つ増やす

    Serial.print("brightness = ");
    Serial.println(brightness);
    Serial.print("count = ");
    Serial.println(count);
    Serial.print("voltage = ");
    Serial.println(voltage);
}

void loop() {
}
```

このコードは次のように出力されます。

```
brightness = 200
count = 1
voltage = 4.85
```

## #define

`#define 名前 値`と書くと、コンパイルする前に「名前」が「値」へ置き換えられます。上のコードの`LED_PIN`は、書き込む前にすべて`12`に置き換わります。

ピン番号のように **プログラム中で変わらない値** に使うのが定番です。LEDを別のピンに繋ぎ変えたくなったときも、`#define`の1行を直すだけで済みます。

!!! warning "`#define`の行にセミコロン`;`は付けません"

    `#define LED_PIN 12;`と書くと`12;`が置き換えられてしまい、エラーの原因になります。

## 変数

`int brightness = 200;`のように **型 名前 = 値;** と書くと変数が作れます。変数は`#define`と違って、`brightness = 150;`のようにプログラムの途中で値を変えられます。

## 型の種類

型は「その変数にどんな値を入れられるか」を決めるものです。Mega2560でよく使うものは次の4つです。

| 型 | 大きさ | 入れられる値 | 使いどころ |
| --- | --- | --- | --- |
| `int` | 16ビット | -32,768 〜 32,767 | ふつうの整数。明るさやカウントなど |
| `unsigned int` | 16ビット | 0 〜 65,535 | マイナスにならない整数 |
| `float` | 32ビット | 約 ±3.4×10<sup>38</sup>(有効数字6〜7桁) | 電圧や距離など小数を含む値 |
| `double` | 32ビット | `float`と同じ | 小数(下の注意を参照) |

!!! warning "Mega2560では`double`は`float`と同じです"

    パソコンのC言語では`double`は8バイトで`float`より精度が高いのですが、Mega2560(AVR)では`double`も4バイトで、`float`とまったく同じ精度になります。

!!! warning "型からあふれた値は壊れます"

    `int`に40,000を入れると入りきらず、まったく違う値になってしまいます(オーバーフロー)。扱う数の大きさに合った型を選んでください。

## 演習

`#define`で3つ目のLEDを繋ぐピンを`SUB_LED_PIN`(9番)として定義し、`int`型の変数`subBrightness`に80を入れて、`analogWrite()`でLEDを光らせるプログラムを書いてください。シリアルモニタにも`subBrightness`の値を表示しましょう。**検証ボタン**でコンパイルが通るか確認してください。

??? tip "ヒントを見る"

    いきなり全部書こうとせず、問題文を「やることリスト」に分けてから、1つずつコードにしていきます。

    | やること | 使うもの |
    | --- | --- |
    | 1. 9番ピンに`SUB_LED_PIN`という名前を付ける | `#define` |
    | 2. 明るさ80を覚えておく入れ物を用意する | `int` |
    | 3. そのピンを出力モードにする | `pinMode()` |
    | 4. その明るさでLEDを光らせる | `analogWrite()` |
    | 5. 値をパソコンに送る | `Serial.print()`・`Serial.println()` |

    1と2は`setup()`より **上** に、3〜5は`setup()`の **中** に書きます。上から順に1つずつ足していけば完成します。

??? success "答えを見る"

    ```cpp
    #define SUB_LED_PIN 9   //3つ目のLEDを繋いだピン番号

    int subBrightness = 80;   //LEDの明るさ(0〜255)

    void setup() {
        Serial.begin(9600);
        pinMode(SUB_LED_PIN, OUTPUT);

        analogWrite(SUB_LED_PIN, subBrightness);

        Serial.print("subBrightness = ");
        Serial.println(subBrightness);
    }

    void loop() {
    }
    ```

    出力は次のようになります。

    ```
    subBrightness = 80
    ```

## 脳内実行してみよう

プログラムは **上から1行ずつ、順番に** 実行されます。その途中で変数の値がどう変わっていくかを紙に書きながら追いかけることをトレースと言います。これができるようになると、動かす前にバグに気づけるようになります。

次のコードを実行すると、シリアルモニタには何が表示されるでしょうか。まず自分で予想してから答えを開いてください。

```cpp
int brightness = 100;

void setup() {
    Serial.begin(9600);

    brightness = brightness + 50;
    brightness = 255;
    brightness = brightness - 100;

    Serial.println(brightness);
}

void loop() {
}
```

??? success "答えを見る"

    答えは **155** です。

    1行ずつ、`brightness`の値を書き出していくとこうなります。

    | 実行する行 | 実行後の`brightness` |
    | --- | --- |
    | `int brightness = 100;` | 100 |
    | `brightness = brightness + 50;` | 150 |
    | `brightness = 255;` | 255 |
    | `brightness = brightness - 100;` | 155 |
    | `Serial.println(brightness);` | 155(これが表示される) |
