# 関数

プログラムが大きくなってくると、`loop()`の中に処理を全部書くと読めなくなってきます。「LEDを点滅させる」「明るさを変える」といったまとまりに名前を付けたものが関数です。

実は`setup()`も`loop()`も関数です。ここでは自分で関数を作れるようになりましょう。

```cpp
#define LED_PIN 12

//LEDを指定した明るさで光らせる関数(戻り値なし)
void setBrightness(int brightness) {
    analogWrite(LED_PIN, brightness);
    Serial.print("LEDの明るさ: ");
    Serial.println(brightness);
}

//パーセントをPWMの0〜255に変換して返す関数(戻り値あり)
int toPwm(int percent) {
    int value = 255 * percent / 100;
    return value;      //計算結果を呼び出し元に返す
}

void setup() {
    Serial.begin(9600);
    pinMode(LED_PIN, OUTPUT);

    int brightness = toPwm(60);   //60%を変換して brightness に入れる
    setBrightness(brightness);

    setBrightness(toPwm(100));    //100%を変換して、そのまま渡す
}

void loop() {
}
```

このコードは次のように出力されます。

```
LEDの明るさ: 153
LEDの明るさ: 255
```

## 関数の作り方

```
戻り値の型 関数名(引数の型 引数名) {
    処理
}
```

- **関数名**: `setBrightness`のように、何をするかが分かる名前を付けます
- **引数(ひきすう)**: 関数に渡す値です。`setBrightness(153)`と呼ぶと、`brightness`に153が入った状態で処理が始まります
- **戻り値(もどりち)**: 関数が呼び出し元に返す値です

作った関数は`setBrightness(200);`のように名前を書くだけで、何度でも呼び出せます。同じ処理を何か所にも書かずに済み、直すときも関数の中だけ直せばよくなります。

## void

`void`は「戻り値がない」という意味です。`setBrightness()`はLEDを光らせるだけで、呼び出し元に返す値がないので`void`にしています。

`setup()`と`loop()`が`void setup()`、`void loop()`と書かれているのも、これらが値を返さない関数だからです。

## return

`return 値;`と書くと、その値を呼び出し元に返して関数を終わります。`toPwm(60)`は`153`を返すので、`int brightness = toPwm(60);`と書くと`brightness`に153が入ります。

戻り値がある関数では、`return`する値の型を関数名の前に書きます。`toPwm()`は整数を返すので`int toPwm(int percent)`です。

`void`の関数でも、`return;`とだけ書けば途中で関数を終わらせることができます。

```cpp
void setBrightness(int brightness) {
    if (brightness > 255) {
        Serial.println("明るすぎます");
        return;             //ここで関数を終わる(LEDは光らせない)
    }
    analogWrite(LED_PIN, brightness);
}
```

!!! warning "関数は使う前に書いておきましょう"

    関数は`setup()`や`loop()`より **上** に書いておくと確実です。下に書くと「そんな関数は知らない」というエラーになることがあります。

## 演習

LEDを指定した回数だけ点滅させる関数`blinkLed(int times)`を作ってください。`setup()`から`blinkLed(3)`と呼び出して、3回点滅することを確かめましょう。点滅の中身は繰り返しの章で書いた`for`文が使えます。

??? tip "ヒントを見る"

    関数は「すでに動いているコードに、名前と`{ }`を付けて外に出す」と考えると作りやすいです。

    | やること | 書き方 |
    | --- | --- |
    | 1. まず1回分の点滅を書いてみる | `digitalWrite(HIGH)` → `delay()` → `digitalWrite(LOW)` → `delay()` |
    | 2. それを繰り返しで囲む | `for (int i = 0; i < times; i++) { }` |
    | 3. 全体に名前と`{ }`を付けて外に出す | `void blinkLed(int times) { }` |
    | 4. `setup()`から呼び出す | `blinkLed(3);` |

    3で`void`にするのは、点滅させるだけで呼び出し元に返す値がないからです。

    繰り返す回数に`3`と直接書かず、**引数の`times`を使う**のがポイントです。`for (int i = 0; i < times; i++)`と書いておけば、`blinkLed(3)`でも`blinkLed(10)`でも同じ関数が使えます。

??? success "答えを見る"

    ```cpp
    #define LED_PIN 12

    //LEDを指定した回数だけ点滅させる関数
    void blinkLed(int times) {
        for (int i = 0; i < times; i++) {
            digitalWrite(LED_PIN, HIGH);
            delay(200);
            digitalWrite(LED_PIN, LOW);
            delay(200);

            Serial.print("点滅 ");
            Serial.println(i + 1);
        }
    }

    void setup() {
        Serial.begin(9600);
        pinMode(LED_PIN, OUTPUT);

        blinkLed(3);   //3回点滅させる
    }

    void loop() {
    }
    ```

    出力は次のようになります。

    ```
    点滅 1
    点滅 2
    点滅 3
    ```

    回数を`times`という引数にしておくと、`blinkLed(5)`と書くだけで5回点滅させられます。関数を作らずに書くと、回数を変えるたびに`for`文をコピーすることになってしまいます。

## 脳内実行してみよう

次のコードを実行すると、シリアルモニタには何が表示されるでしょうか。

```cpp
int twice(int x) {
    return x * 2;
}

void setup() {
    Serial.begin(9600);

    int a = twice(10);
    int b = twice(a) + 5;

    Serial.println(a);
    Serial.println(b);
}

void loop() {
}
```

??? success "答えを見る"

    ```
    20
    45
    ```

    | 順番 | 実行する場所 | 何が起きるか |
    | --- | --- | --- |
    | 1 | `int a = twice(10);` | `twice`へジャンプ。`x`に10が入る |
    | 2 | `return x * 2;` | 10 × 2 = 20 を持って戻る |
    | 3 | `int a = twice(10);` | 呼んだ場所が`20`に置き換わり、`a`は **20** |
    | 4 | `int b = twice(a) + 5;` | `a`は20なので`twice(20)`。`x`に20が入る |
    | 5 | `return x * 2;` | 20 × 2 = 40 を持って戻る |
    | 6 | `int b = twice(a) + 5;` | `40 + 5`が計算され、`b`は **45** |

    関数を呼んだ部分は、実行が終わると **その場所が戻り値そのものに置き換わる** と考えてください。

    ```
    int b = twice(20) + 5;
    int b = 40 + 5;
    int b = 45;
    ```
