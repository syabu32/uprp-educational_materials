# 演算子

LEDの明るさを計算したり、センサーの値がしきい値を超えたか調べたりするときに使うのが演算子です。マイコンのプログラムでは「パーセントで指定した明るさをPWMの0〜255に変換する」といった計算が頻繁に出てきます。

```cpp
#define LED_PIN 12

int percent = 60;      //出したい明るさ(%)
int brightness = 0;    //analogWriteに渡す値(0〜255)

void setup() {
    Serial.begin(9600);
    pinMode(LED_PIN, OUTPUT);

    brightness = 255 * percent / 100;   //60%の明るさを0〜255に変換する
    analogWrite(LED_PIN, brightness);
    Serial.print("brightness = ");
    Serial.println(brightness);

    brightness += 40;                   //40だけ明るくする(brightness = brightness + 40 と同じ)
    analogWrite(LED_PIN, brightness);
    Serial.print("brightness = ");
    Serial.println(brightness);
}

void loop() {
}
```

このコードは次のように出力されます。

```
brightness = 153
brightness = 193
```

## 算術演算子

計算に使う演算子です。

| 演算子 | 意味 | 例 |
| --- | --- | --- |
| `+` | 足し算 | `brightness + 40` |
| `-` | 引き算 | `brightness - 40` |
| `*` | かけ算 | `255 * percent` |
| `/` | 割り算 | `value / 100` |
| `%` | 割った余り | `count % 3` |

`%`は「3回に1回だけLEDを光らせる」のように、周期的な処理を作るときによく使います。数を数えながら`%`で余りを求めると、その余りが **同じ並びを繰り返す** からです。

実際に0から8まで数えて、3で割った余りを表示してみます。

```cpp
void setup() {
    Serial.begin(9600);

    for (int count = 0; count < 9; count++) {
        Serial.print(count);
        Serial.print(" → 余り ");
        Serial.println(count % 3);
    }
}

void loop() {
}
```

このコードは次のように出力されます。

```
0 → 余り 0
1 → 余り 1
2 → 余り 2
3 → 余り 0
4 → 余り 1
5 → 余り 2
6 → 余り 0
7 → 余り 1
8 → 余り 2
```

`count`はどんどん増えていくのに、`count % 3`は **0→1→2→0→1→2** と3つの値をぐるぐる繰り返しています。これが「周期」です。`% 4`にすれば0〜3の4種類、`% 10`にすれば0〜9の10種類の周期になります。

余りが0になるのは`count`が0、3、6のとき、つまり **3回に1回** です。次の章の`if`と組み合わせて「`count % 3`が0のときだけLEDを光らせる」と書けば、3回に1回だけ光らせる処理が作れます。

!!! warning "整数どうしの割り算は小数点以下が切り捨てられます"

    上のコードを`brightness = percent / 100 * 255;`と書き換えると、`60 / 100`が **0** になってしまい、結果は0です。整数の割り算では小数が消えるので、**先にかけ算をしてから割る**のが基本です。

## 比較演算子

2つの値をくらべて、正しければ`true`、違えば`false`になります。次の章の`if`と組み合わせて使います。

| 演算子 | 意味 |
| --- | --- |
| `==` | 等しい |
| `!=` | 等しくない |
| `<` | より小さい |
| `>` | より大きい |
| `<=` | 以下 |
| `>=` | 以上 |

## ブール演算子

複数の条件を組み合わせます。

| 演算子 | 意味 | 例 |
| --- | --- | --- |
| `&&` | かつ(両方とも正しい) | `brightness > 0 && voltage > 7.0` |
| <code>&#124;&#124;</code> | または(どちらかが正しい) | <code>brightness == 0 &#124;&#124; percent == 0</code> |
| `!` | ではない(否定) | `!isBlinking` |

「明るさが0より大きい **かつ** バッテリー電圧が7Vより上」のように、複数の条件をまとめて調べたいときに使います。

## 複合演算子

「今の値を使って計算し、その結果を同じ変数に入れ直す」書き方を短くできます。

| 演算子 | 意味 | 例 |
| --- | --- | --- |
| `+=` | 足して代入 | `brightness += 40` |
| `-=` | 引いて代入 | `brightness -= 40` |
| `*=` | かけて代入 | `brightness *= 2` |
| `/=` | 割って代入 | `brightness /= 2` |
| `++` | 1増やす | `count += 1` |
| `--` | 1減らす | `count -= 1` |

PWMの章の`for (int value = 0; value <= 254; value++)`で使った`value++`も複合演算子の仲間です。

## 演習

`int percent = 80;`として、80%の明るさに対応するPWMの値を計算し、`analogWrite()`でLEDを光らせてシリアルモニタにも表示するプログラムを書いてください。

??? tip "ヒントを見る"

    `analogWrite()`が受け取れるのは0〜255なので「0~100%を0〜255に直す」という計算をはさみます。

    | やること | 書き方 |
    | --- | --- |
    | 1. 明るさ(%)を覚える入れ物を用意する | `int percent = 80;` |
    | 2. 0〜255に変換した値を入れる入れ物を用意する | `int brightness = 0;` |
    | 3. %を0〜255に変換する | `brightness = 255 * percent / 100;` |
    | 4. その値でLEDを光らせる | `analogWrite(LED_PIN, brightness);` |
    | 5. 値をパソコンに送る | `Serial.print()`・`Serial.println()` |

    3の式は「100%のときに255になる」ように作ります。全体(255)のうち80%分がほしいので、**255に0.8をかける**わけです。ただし整数では0.8が作れないので、**先に255をかけてから100で割る**という順番にします。

??? success "答えを見る"

    ```cpp
    #define LED_PIN 12

    int percent = 80;      //出したい明るさ(%)
    int brightness = 0;    //analogWriteに渡す値(0〜255)

    void setup() {
        Serial.begin(9600);
        pinMode(LED_PIN, OUTPUT);

        brightness = 255 * percent / 100;   //先にかけ算をしてから割る
        analogWrite(LED_PIN, brightness);

        Serial.print("brightness = ");
        Serial.println(brightness);
    }

    void loop() {
    }
    ```

    出力は次のようになります。

    ```
    brightness = 204
    ```

## 脳内実行してみよう

次のコードを実行すると、シリアルモニタには何が表示されるでしょうか。

```cpp
int x = 7;

void setup() {
    Serial.begin(9600);

    int y = x / 2;
    int z = x % 2;
    x += 3;
    x++;

    Serial.print("y = ");
    Serial.println(y);
    Serial.print("z = ");
    Serial.println(z);
    Serial.print("x = ");
    Serial.println(x);
}

void loop() {
}
```

??? success "答えを見る"

    ```cpp
    y = 3
    z = 1
    x = 11
    ```

    - `int y = x / 2;` → `7 / 2`の本当の答えは3.5ですが、整数どうしの割り算なので小数点以下が切り捨てられて **3** になります
    - `int z = x % 2;` → `%`は「割った余り」です。7を2で割ると3あまり1なので **1** です
    - `x += 3;` → `x = x + 3`と同じ意味なので、7 + 3 で **10** になります
    - `x++;` → `x = x + 1`と同じ意味なので、10 + 1 で **11** になります
