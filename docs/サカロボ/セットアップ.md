# セットアップ

マイコンの使い方がわかったので、Arduino IDEでArduino Mega2560用のプログラムを書くためのセットアップを始めましょう！

ノートパソコンを用意したら、Arduino IDEを開きます。アップデートを一通り済ませ、最新の状態にしてください。

できたら、左の本棚のマーク(ライブラリマネージャー)から **PS4Controller** と **USB Host Shield Library 2.0** を検索してインストールします。

左上の **ファイル** → **新規スケッチ** を選択し、まっさらな状態を用意します。以下のコードになっていれば大丈夫です。

```cpp
void setup() {
    // put your setup code here, to run once:
}

void loop() {
    //put your main code here, to run repeatedly:
}
```

次に、上の **ボードを選択** からArduino Mega or Mega 2560を選択してOKを押します。

左上のチェックマーク(検証)を押してエラーが無ければ成功です！この検証は、プログラムが正しく書けているか確認するときに毎回使います。
