# モーターを動かす

モータードライバの向きと速さの決め方がわかったので、実際にモーターを1つ動かしてみましょう。モータードライバのENA・IN1・IN2をマイコンに繋いで、正転→停止→逆転→停止を繰り返します。

```cpp
#define MOTOR_EN 5     //ENA(速さ)
#define MOTOR_IN1 22   //IN1(向き)
#define MOTOR_IN2 23   //IN2(向き)

void setup() {
    Serial.begin(9600);
    pinMode(MOTOR_EN, OUTPUT);
    pinMode(MOTOR_IN1, OUTPUT);
    pinMode(MOTOR_IN2, OUTPUT);
}

void loop() {
    //正転
    digitalWrite(MOTOR_IN1, HIGH);
    digitalWrite(MOTOR_IN2, LOW);
    analogWrite(MOTOR_EN, 200);
    Serial.println("正転");
    delay(2000);

    //ブレーキで止める
    digitalWrite(MOTOR_IN1, LOW);
    digitalWrite(MOTOR_IN2, LOW);
    analogWrite(MOTOR_EN, 255);
    Serial.println("停止");
    delay(1000);

    //逆転
    digitalWrite(MOTOR_IN1, LOW);
    digitalWrite(MOTOR_IN2, HIGH);
    analogWrite(MOTOR_EN, 200);
    Serial.println("逆転");
    delay(2000);

    //ブレーキで止める
    digitalWrite(MOTOR_IN1, LOW);
    digitalWrite(MOTOR_IN2, LOW);
    analogWrite(MOTOR_EN, 255);
    Serial.println("停止");
    delay(1000);
}
```

このコードは次のように出力されます。

```
正転
停止
逆転
停止
.
.
.
```

## ピンの選び方

- **ENA**: 速さを`analogWrite()`で変えるので、**PWM対応のピン** (2〜13番、44〜46番)に繋ぎます。今回は5番を使います
- **IN1・IN2**: HIGHかLOWだけなので、**どのDigital Pinでも** 使えます。今回は22番・23番を使います

!!! warning "9番・10番、50〜52番はUSBホストシールドが使います"

    ロボットではPS4コントローラーのためにUSBホストシールドを載せます。USBホストシールドは9番・10番と、50〜52番(ICSP端子)を使うので、モーター用には使わないようにしましょう。

逆向きに切り替えるときは、上のコードのように **一度止めてから** 切り替えると、モーターやモータードライバに負担がかかりにくくなります。

## 関数にまとめる

上のコードは同じような3行が何度も出てきて読みにくいので、関数の章で学んだように「正転させる」「逆転させる」「止める」を関数にまとめます。

```cpp
#define MOTOR_EN 5     //ENA(速さ)
#define MOTOR_IN1 22   //IN1(向き)
#define MOTOR_IN2 23   //IN2(向き)

//正転させる
void forward(int speed) {
    digitalWrite(MOTOR_IN1, HIGH);
    digitalWrite(MOTOR_IN2, LOW);
    analogWrite(MOTOR_EN, speed);
}

//逆転させる
void backward(int speed) {
    digitalWrite(MOTOR_IN1, LOW);
    digitalWrite(MOTOR_IN2, HIGH);
    analogWrite(MOTOR_EN, speed);
}

//ブレーキで止める
void stopMotor() {
    digitalWrite(MOTOR_IN1, LOW);
    digitalWrite(MOTOR_IN2, LOW);
    analogWrite(MOTOR_EN, 255);
}

void setup() {
    Serial.begin(9600);
    pinMode(MOTOR_EN, OUTPUT);
    pinMode(MOTOR_IN1, OUTPUT);
    pinMode(MOTOR_IN2, OUTPUT);
}

void loop() {
    forward(200);
    Serial.println("正転");
    delay(2000);

    stopMotor();
    Serial.println("停止");
    delay(1000);

    backward(200);
    Serial.println("逆転");
    delay(2000);

    stopMotor();
    Serial.println("停止");
    delay(1000);
}
```

出力は最初のコードと同じです。`loop()`を読むだけで「正転→停止→逆転→停止」と動きがわかるようになりました。ピンの細かい操作は関数の中に隠れています。

## 演習

上の関数を使って、モーターを「ゆっくり正転(速さ100)を1秒 → 速く正転(速さ255)を1秒 → 停止を1秒」の順に繰り返すプログラムを書いてください。

??? tip "ヒントを見る"

    関数はもう作ってあるので、`loop()`の中で **呼ぶ順番と引数** を決めるだけです。

    | やること | 書き方 |
    | --- | --- |
    | 1. ゆっくり正転 | `forward(100);` |
    | 2. 1秒待つ | `delay(1000);` |
    | 3. 速く正転 | `forward(255);` |
    | 4. 1秒待つ | `delay(1000);` |
    | 5. 止める | `stopMotor();` |
    | 6. 1秒待つ | `delay(1000);` |

    今回は逆転しないので、`backward()`は書かなくても動きます。

??? success "答えを見る"

    ```cpp
    #define MOTOR_EN 5     //ENA(速さ)
    #define MOTOR_IN1 22   //IN1(向き)
    #define MOTOR_IN2 23   //IN2(向き)

    //正転させる

        digitalWrite(MOTOR_IN1, HIGH);
        digitalWrite(MOTOR_IN2, LOW);
        analogWrite(MOTOR_EN, speed);
    }

    //ブレーキで止める
    void stopMotor() {
        digitalWrite(MOTOR_IN1, LOW);
        digitalWrite(MOTOR_IN2, LOW);
        analogWrite(MOTOR_EN, 255);
    }

    void setup() {
        Serial.begin(9600);

        pinMode(MOTOR_IN1, OUTPUT);

        forward(100);
        Serial.println("ゆっくり正転");

        Serial.println("速く正転");
        delay(1000);

        stopMotor();
        Serial.println("停止");
        delay(1000);
    }
    ```

    出力は次のようになります。

    ```
    ゆっくり正転
    速く正転
    停止
    .
    .
    .
    ```

## 脳内実行してみよう

上の`forward()`・`backward()`・`stopMotor()`を使って、`setup()`の最後に次の4行を実行しました。すべて実行し終わったとき、IN1・IN2・ENAはそれぞれどうなっていて、モーターはどう動いているでしょうか。

```cpp
forward(150);
stopMotor();
backward(80);
forward(0);
```

??? success "答えを見る"

    IN1は **HIGH**、IN2は **LOW**、ENAは **0** で、モーターは **フリー(惰性で止まる)** です。

    | 実行する行 | IN1 | IN2 | ENA | モーターの動き |
    | --- | --- | --- | --- | --- |
    | `forward(150);` | HIGH | LOW | 150 | 正転 |
    | `stopMotor();` | LOW | LOW | 255 | ブレーキ |
    | `backward(80);` | LOW | HIGH | 80 | ゆっくり逆転 |
    | `forward(0);` | HIGH | LOW | 0 | フリー |

    関数の名前は`forward`ですが、速さが0なのでモーターは回りません。ENAが0のときはIN1・IN2に関係なくフリーになります(「モータードライバを知る」の表の一番下の行)。関数の名前だけで判断せず、**最後にピンがどうなったか** を追うのが大事です。
