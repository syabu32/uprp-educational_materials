# ドライバプログラムを作る

いよいよ、最終的なロボットのプログラムで使う「1つのモーターを動かすドライバプログラム」を完成させます。ここで作る`Motor`構造体を、ロボットの7つのモーター全部に使っていきます。

前の章では`forward()`・`backward()`・`stop()`と、動かし方ごとに関数を分けていました。ここではそれを`run(int speed)`という **1つの関数** にまとめます。

```cpp
struct Motor {
    int en;    //ENAを繋いだピン(PWM)
    int in1;   //IN1を繋いだピン
    int in2;   //IN2を繋いだピン

    //ブレーキで止める
    void stop() {
        digitalWrite(in1, LOW);
        digitalWrite(in2, LOW);
        analogWrite(en, 255);
    }

    //ピンを出力モードにして、止まった状態から始める(setupで1回呼ぶ)
    void begin() {
        pinMode(en, OUTPUT);
        pinMode(in1, OUTPUT);
        pinMode(in2, OUTPUT);
        stop();
    }

    //speedが+なら正転、-なら逆転、0なら停止(-255〜255)
    void run(int speed) {
        if (speed > 255) {
            speed = 255;
        } else if (speed < -255) {
            speed = -255;
        }

        if (speed > 0) {
            digitalWrite(in1, HIGH);
            digitalWrite(in2, LOW);
            analogWrite(en, speed);
        } else if (speed < 0) {
            digitalWrite(in1, LOW);
            digitalWrite(in2, HIGH);
            analogWrite(en, -speed);   //analogWriteには+の値を渡す
        } else {
            stop();
        }
    }
};

Motor leftMotor = {5, 22, 23};

void setup() {
    Serial.begin(9600);
    leftMotor.begin();
}

void loop() {
    leftMotor.run(200);
    Serial.println("run(200): 正転");
    delay(2000);

    leftMotor.run(0);
    Serial.println("run(0): 停止");
    delay(1000);

    leftMotor.run(-150);
    Serial.println("run(-150): 逆転");
    delay(2000);

    leftMotor.run(0);
    Serial.println("run(0): 停止");
    delay(1000);
}
```

このコードは次のように出力されます。

```
run(200): 正転
run(0): 停止
run(-150): 逆転
run(0): 停止
.
.
.
```

## 速さを1つの数で表す

`run()`は、向きと速さを **1つの数** で受け取ります。

| `run()`に渡す値 | モーターの動き |
| --- | --- |
| 1〜255(+) | 正転。数が大きいほど速い |
| 0 | 停止(ブレーキ) |
| -1〜-255(-) | 逆転。-255に近いほど速い |

こうしておくと、あとでPS4コントローラーのスティックの傾きから計算した値を、そのまま`run()`に渡すだけでモーターを動かせるようになります。「傾きが+なら`forward()`、-なら`backward()`」と毎回書き分ける必要がありません。

## run()の中身

`run()`の中は、上から順に2つのことをしています。

**1. 範囲の外の値を直す**

`analogWrite()`は0〜255しか受け取れないので、`speed`が255より大きければ255に、-255より小さければ-255に直します。条件分岐の章でLEDの明るさを255に直したのと同じ安全装置です。

**2. 符号で向きを決める**

- `speed > 0` → IN1をHIGH、IN2をLOWにして正転
- `speed < 0` → IN1をLOW、IN2をHIGHにして逆転
- どちらでもない(0) → `stop()`でブレーキ

逆転のときは`speed`がマイナスなので、`analogWrite(en, -speed)`と **マイナスを付けて+の値に戻して** から渡しています。`speed`が-150なら`-speed`は150です。

!!! warning "`analogWrite()`にマイナスの値を渡さないでください"

    `analogWrite(en, speed)`と書いて-150をそのまま渡すと、正しい速さになりません。逆転のときは必ず+の値にしてから渡しましょう。

`begin()`の中で`stop()`を呼んでいるのは、電源を入れた直後にモーターが勝手に回り出さないようにするためです。

## 使い方

| 書き方 | 意味 |
| --- | --- |
| `Motor leftMotor = {5, 22, 23};` | ENA=5、IN1=22、IN2=23のモーターを作る |
| `leftMotor.begin();` | ピンを準備する(`setup()`で1回) |
| `leftMotor.run(200);` | 速さ200で正転 |
| `leftMotor.run(-150);` | 速さ150で逆転 |
| `leftMotor.run(0);` | 止める |
| `leftMotor.stop();` | 止める(`run(0)`と同じ) |

モーターを増やすときは、`Motor`の実物を増やして`begin()`を呼ぶだけです。構造体の中身は書き換えません。

## 演習

モータードライバのモーターB(ENB=6番、IN3=24番、IN4=25番)に繋いだ`rightMotor`を追加して、左右のモーターで「前進(左右とも200)2秒 → 右回転(左200・右-200)1秒 → 停止1秒」を繰り返すプログラムを書いてください。`Motor`構造体は上のものをそのまま使います。

??? tip "ヒントを見る"

    `Motor`構造体の中は触りません。変えるのは構造体の **外側** だけです。

    | やること | 書き方 |
    | --- | --- |
    | 1. 右モーターの実物を作る | `Motor rightMotor = {6, 24, 25};` |
    | 2. `setup()`で右モーターも準備する | `rightMotor.begin();` |
    | 3. 前進: 両方に+の値 | `leftMotor.run(200);` と `rightMotor.run(200);` |
    | 4. 右回転: 左は+、右は- | `leftMotor.run(200);` と `rightMotor.run(-200);` |
    | 5. 停止: 両方0 | `leftMotor.run(0);` と `rightMotor.run(0);` |

    それぞれの動きのあとに`delay()`で待つのを忘れないようにしましょう。

??? success "答えを見る"

    ```cpp
    struct Motor {
        int en;    //ENAを繋いだピン(PWM)
        int in1;   //IN1を繋いだピン
        int in2;   //IN2を繋いだピン

        //ブレーキで止める
        void stop() {
            digitalWrite(in1, LOW);
            digitalWrite(in2, LOW);
            analogWrite(en, 255);
        }

        //ピンを出力モードにして、止まった状態から始める(setupで1回呼ぶ)
        void begin() {
            pinMode(en, OUTPUT);
            pinMode(in1, OUTPUT);
            pinMode(in2, OUTPUT);
            stop();
        }

        //speedが+なら正転、-なら逆転、0なら停止(-255〜255)
        void run(int speed) {
            if (speed > 255) {
                speed = 255;
            } else if (speed < -255) {
                speed = -255;
            }

            if (speed > 0) {
                digitalWrite(in1, HIGH);
                digitalWrite(in2, LOW);
                analogWrite(en, speed);
            } else if (speed < 0) {
                digitalWrite(in1, LOW);
                digitalWrite(in2, HIGH);
                analogWrite(en, -speed);   //analogWriteには+の値を渡す
            } else {
                stop();
            }
        }
    };

    Motor leftMotor = {5, 22, 23};    //ENA・IN1・IN2
    Motor rightMotor = {6, 24, 25};   //ENB・IN3・IN4

    void setup() {
        Serial.begin(9600);
        leftMotor.begin();
        rightMotor.begin();
    }

    void loop() {
        leftMotor.run(200);
        rightMotor.run(200);
        Serial.println("前進");
        delay(2000);

        leftMotor.run(200);
        rightMotor.run(-200);
        Serial.println("右回転");
        delay(1000);

        leftMotor.run(0);
        rightMotor.run(0);
        Serial.println("停止");
        delay(1000);
    }
    ```

    出力は次のようになります。

    ```
    前進
    右回転
    停止
    .
    .
    .
    ```

    実際のロボットで右回転のつもりが左回転になったときは、モーターの取り付けの向きや配線によるものです。「モータードライバを知る」で説明したように、OUT1とOUT2の線を入れ替えるか、`run()`に渡す値の+と-を入れ替えて直します。

## 脳内実行してみよう

上の`Motor`構造体を使って、`setup()`で次の2行を実行しました。実行し終わったとき、`leftMotor`のIN1・IN2・ENAはそれぞれどうなっているでしょうか。

```cpp
leftMotor.begin();
leftMotor.run(-300);
```

??? success "答えを見る"

    IN1は **LOW**、IN2は **HIGH**、ENAは **255** です。モーターは全速で逆転しています。

    `run(-300)`の中を1行ずつ追いかけます。

    | 実行する行 | `speed` | 何が起きるか |
    | --- | --- | --- |
    | `run(-300)`が呼ばれる | -300 | |
    | `if (speed > 255)` | -300 | 違うので次の`else if`へ |
    | `else if (speed < -255)` | -300 | 正しい |
    | `speed = -255;` | -255 | 範囲の中に直る |
    | `if (speed > 0)` | -255 | 違うので次の`else if`へ |
    | `else if (speed < 0)` | -255 | 正しいので逆転の処理へ |
    | `digitalWrite(in1, LOW);` | -255 | IN1がLOW |
    | `digitalWrite(in2, HIGH);` | -255 | IN2がHIGH |
    | `analogWrite(en, -speed);` | -255 | `-speed`は255なので、ENAが255 |

    -300は範囲の外なので、まず-255に直されてから向きが決まります。最後の`-speed`は「-255にマイナスを付ける」ので **255** になります。
