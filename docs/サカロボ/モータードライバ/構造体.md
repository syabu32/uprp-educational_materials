# 構造体

前の章ではモーター1つを動かすのに、`#define`を3つと関数を3つ書きました。ですがロボットにはモーターが7つあります。同じやり方だと`#define`が21個になり、関数も`forwardLeft()`・`forwardRight()`…とモーターの数だけ必要になってしまいます。

そこで、「ENA・IN1・IN2の3つのピン」をひとまとまりにして、**1つのモーター** として扱えるようにします。そのための仕組みが構造体です。

```cpp
struct Motor {
    int en;    //ENAを繋いだピン
    int in1;   //IN1を繋いだピン
    int in2;   //IN2を繋いだピン
};

Motor leftMotor = {5, 22, 23};
Motor rightMotor = {6, 24, 25};

void setup() {
    Serial.begin(9600);

    Serial.print("左モーターのENA: ");
    Serial.println(leftMotor.en);
    Serial.print("右モーターのIN1: ");
    Serial.println(rightMotor.in1);
}

void loop() {
}
```

このコードは次のように出力されます。

```
左モーターのENA: 5
右モーターのIN1: 24
```

## 構造体の作り方

```
struct 構造体の名前 {
    型 メンバ名;
    型 メンバ名;
};
```

`struct Motor { ... };`は「モーターにはen・in1・in2という3つの値がある」という **設計図** です。設計図の中に書いた変数を **メンバ** と呼びます。

設計図を書いただけではまだモーターはありません。`Motor leftMotor = {5, 22, 23};`と書くと、設計図から`leftMotor`という **実物** が1つ作られます。`{ }`の中の値は、設計図に書いた順番(en → in1 → in2)で入ります。

`rightMotor`も同じ設計図から作りますが、中身は別々です。`leftMotor`の`in1`は22、`rightMotor`の`in1`は24です。

!!! warning "構造体の最後の`};`を忘れないでください"

    構造体の`}`のあとにはセミコロン`;`が必要です。関数の`}`には付けないので、忘れやすいところです。

## メンバを使う

`leftMotor.en`のように **実物の名前.メンバ名** と書くと、その実物のメンバを使えます。`.`は「〜の」と読むとわかりやすいです。`leftMotor.en`は「左モーターのen」です。

## メンバ関数

構造体の中には関数も書けます。構造体の中に書いた関数を **メンバ関数** と呼びます。メンバ関数の中では、`en`・`in1`・`in2`をそのまま使えます。

```cpp
struct Motor {
    int en;    //ENAを繋いだピン
    int in1;   //IN1を繋いだピン
    int in2;   //IN2を繋いだピン

    //ピンを出力モードにする
    void begin() {
        pinMode(en, OUTPUT);
        pinMode(in1, OUTPUT);
        pinMode(in2, OUTPUT);
    }

    //正転させる
    void forward(int speed) {
        digitalWrite(in1, HIGH);
        digitalWrite(in2, LOW);
        analogWrite(en, speed);
    }
};

Motor leftMotor = {5, 22, 23};
Motor rightMotor = {6, 24, 25};

void setup() {
    Serial.begin(9600);
    leftMotor.begin();
    rightMotor.begin();

    leftMotor.forward(200);
    rightMotor.forward(100);
}

void loop() {
}
```

メンバ関数も`leftMotor.forward(200)`のように **実物の名前.関数名()** で呼び出します。

ポイントは、**同じ`forward()`でも、どの実物から呼んだかで使うピンが変わる** ことです。

| 呼び出し | `in1` | `en` | 実際に動くピン |
| --- | --- | --- | --- |
| `leftMotor.forward(200);` | 22 | 5 | 22番をHIGH、5番に200 |
| `rightMotor.forward(100);` | 24 | 6 | 24番をHIGH、6番に100 |

前の章では関数の中にピン番号(`MOTOR_IN1`など)を直接書いていたので、モーターごとに関数が必要でした。構造体にすると関数は1つで済み、モーターが7つに増えても`Motor`の実物を7つ作るだけで済みます。

## 演習

上の`Motor`構造体に、逆転させるメンバ関数`backward(int speed)`と、ブレーキで止めるメンバ関数`stop()`を追加してください。そして`leftMotor`を「正転(速さ200)2秒 → 停止1秒 → 逆転(速さ200)2秒 → 停止1秒」と繰り返し動かしましょう。

??? tip "ヒントを見る"

    前の章の`backward()`と`stopMotor()`を、構造体の中に移すイメージです。

    | やること | 書き方 |
    | --- | --- |
    | 1. `backward()`を構造体の中にコピーする | `forward()`の下に置く |
    | 2. ピンの名前をメンバに変える | `MOTOR_IN1` → `in1`、`MOTOR_IN2` → `in2`、`MOTOR_EN` → `en` |
    | 3. `stopMotor()`も同じようにコピーして名前を`stop()`にする | 2と同じくピンの名前を変える |
    | 4. `loop()`から呼び出す | `leftMotor.forward(200);`、`leftMotor.stop();`など |

    構造体の中なので、`#define`はもう使いません。

??? success "答えを見る"

    ```cpp
    struct Motor {
        int en;    //ENAを繋いだピン
        int in1;   //IN1を繋いだピン
        int in2;   //IN2を繋いだピン

        //ピンを出力モードにする
        void begin() {
            pinMode(en, OUTPUT);
            pinMode(in1, OUTPUT);
            pinMode(in2, OUTPUT);
        }

        //正転させる
        void forward(int speed) {
            digitalWrite(in1, HIGH);
            digitalWrite(in2, LOW);
            analogWrite(en, speed);
        }

        //逆転させる
        void backward(int speed) {
            digitalWrite(in1, LOW);
            digitalWrite(in2, HIGH);
            analogWrite(en, speed);
        }

        //ブレーキで止める
        void stop() {
            digitalWrite(in1, LOW);
            digitalWrite(in2, LOW);
            analogWrite(en, 255);
        }
    };

    Motor leftMotor = {5, 22, 23};

    void setup() {
        Serial.begin(9600);
        leftMotor.begin();
    }

    void loop() {
        leftMotor.forward(200);
        Serial.println("正転");
        delay(2000);

        leftMotor.stop();
        Serial.println("停止");
        delay(1000);

        leftMotor.backward(200);
        Serial.println("逆転");
        delay(2000);

        leftMotor.stop();
        Serial.println("停止");
        delay(1000);
    }
    ```

    出力は次のようになります。

    ```
    正転
    停止
    逆転
    停止
    .
    .
    .
    ```

## 脳内実行してみよう

次のコードを実行すると、シリアルモニタには何が表示されるでしょうか。

```cpp
struct Motor {
    int en;
    int in1;
    int in2;

    void forward(int speed) {
        Serial.print(in1);
        Serial.print("番をHIGH、");
        Serial.print(en);
        Serial.print("番に");
        Serial.println(speed);
    }
};

Motor leftMotor = {5, 22, 23};
Motor rightMotor = {6, 24, 25};

void setup() {
    Serial.begin(9600);

    rightMotor.forward(120);
    leftMotor.forward(200);
}

void loop() {
}
```

??? success "答えを見る"

    ```
    24番をHIGH、6番に120
    22番をHIGH、5番に200
    ```

    | 順番 | 実行する行 | `in1` | `en` | `speed` |
    | --- | --- | --- | --- | --- |
    | 1 | `rightMotor.forward(120);` | 24 | 6 | 120 |
    | 2 | `leftMotor.forward(200);` | 22 | 5 | 200 |

    `forward()`の中の`in1`や`en`は、**呼び出したときの`.`の左側の実物のメンバ** になります。`rightMotor.forward()`なら`rightMotor`の値、`leftMotor.forward()`なら`leftMotor`の値です。

    また、`{6, 24, 25}`は構造体に書いた順番の通り、en=6、in1=24、in2=25と入っています。
