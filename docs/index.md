# ドキュメントの使い方

このサイトは [Zensical](https://zensical.org/) という静的サイトジェネレーターでMarkdownから生成し、GitHub Pagesで公開しています。

- **左のナビゲーション**: 章ごとにページが並んでいます。配線・プログラムなど、知りたい項目をクリックして移動してください。
- **上部の検索窓**: キーワードで全ページを横断検索できます。
- **右のページ内目次**: 見出しの一覧が出るので、長いページでも読みたい場所にすぐ飛べます。
- **コードブロックのコピー**: 配線用スクリプトやコマンド例には右上にコピー用ボタンが付いているので、そのまま貼り付けて使えます。

ドキュメントは内容ができたページから順番に追加・公開していきます。
